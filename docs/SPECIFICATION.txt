1. MATHEMATICAL FORMALISM & SYSTEM FOUNDATIONS

The engine models physical and abstract dynamic phenomena on an unconstrained,
finite-dimensional, smooth canonical symplectic phase space manifold
\mathcal{M} = T^*Q \cong \mathbb{R}^{2d}, parametrized by generalized canonical
coordinates:
z = \begin{bmatrix} q \\ p \end{bmatrix} \in \mathbb{R}^{2d}, \quad q \in \mathbb{R}^d \text{ (configuration)}, \quad p \in \mathbb{R}^d \text{ (conjugate momentum)}

1.1. Differential Geometric Invariants

The manifold is equipped with a closed, non-degenerate, differential 2-form (the
canonical symplectic form) \omega \in \Omega^2(\mathcal{M}):
\omega = \sum_{i=1}^d dq^i \wedge dp^i \iff \omega(u, v) = u^T J v, \quad \forall u, v \in T_z\mathcal{M}
where J \in \text{Sp}(2d, \mathbb{R}) is the canonical skew-symmetric symplectic
matrix:
J = \begin{bmatrix} \mathbf{0}_d & \mathbf{I}_d \\ -\mathbf{I}_d & \mathbf{0}_d \end{bmatrix}, \quad J^T = -J = J^{-1}, \quad \det(J) = 1, \quad J^2 = -\mathbf{I}_{2d}

1.2. Hamiltonian Dynamics & Symplectomorphism Flow

Given a continuously differentiable parameterized energy functional
H_\theta: \mathcal{M} \to \mathbb{R}, the temporal evolution of any system state
obeys Hamilton's canonical vector field X_H \in \mathfrak{X}(\mathcal{M}):
\dot{z}(t) = X_H(z(t)) = J \nabla_z H_\theta(z(t)) \iff \begin{cases} \dot{q} = \nabla_p H_\theta(q, p) \\ \dot{p} = -\nabla_q H_\theta(q, p) \end{cases}
The trajectory map \Phi_t: \mathcal{M} \to \mathcal{M} induced by X_H defines an
exact 1-parameter group of symplectomorphisms satisfying:
\left( \frac{\partial \Phi_t(z)}{\partial z} \right)^T J \left( \frac{\partial \Phi_t(z)}{\partial z} \right) = J, \quad \det\left( \frac{\partial \Phi_t(z)}{\partial z} \right) = 1 \quad \forall t \in \mathbb{R}

1.3. Poisson Lie Algebra & Noether Conservation

For smooth functionals F, G \in C^\infty(\mathcal{M}), the bilinear,
antisymmetric Poisson bracket is defined by:
\{F, G\} = \omega(X_F, X_G) = (\nabla_z F)^T J (\nabla_z G) = \sum_{i=1}^d \left( \frac{\partial F}{\partial q^i} \frac{\partial G}{\partial p^i} - \frac{\partial F}{\partial p^i} \frac{\partial G}{\partial q^i} \right)
By Noether's Theorem, a functional Q_\phi \in C^\infty(\mathcal{M}) corresponds
to an invariant of motion along the system trajectory generated by H_\theta if
and only if its Lie derivative along X_H vanishes:
\mathcal{L}_{X_H} Q_\phi = \frac{d Q_\phi}{dt} = \{Q_\phi, H_\theta\} = (\nabla_z Q_\phi)^T J (\nabla_z H_\theta) \equiv 0
When multiple invariants \{Q_1, \dots, Q_k\} commute closure-wise, they define
the basis of a Lie algebra \mathfrak{g} with structure constants c_{ab}^c:
\{Q_a, Q_b\} = \sum_{c=1}^k c_{ab}^c Q_c

3.2. math_core/symplectic.py

  - Purpose: Implements the intrinsic symplectic geometry operators,
    differential 2-form evaluation, Poisson bracket algebra, and Hamiltonian
    vector field calculations.
  - Mathematical Operations:
      - Canonical Symplectic Matrix generation:
        J = \begin{bmatrix} \mathbf{0}_{d \times d} & \mathbf{I}_{d \times d} \\ -\mathbf{I}_{d \times d} & \mathbf{0}_{d \times d} \end{bmatrix}
      - Canonical Poisson Bracket between arbitrary differentiable scalar fields
        f, g: \mathbb{R}^{2d} \to \mathbb{R}:
        \{f, g\}(z) = \left(\nabla_z f\right)^T J \left(\nabla_z g\right) = \sum_{i=1}^d \left( \frac{\partial f}{\partial z_i} \frac{\partial g}{\partial z_{i+d}} - \frac{\partial f}{\partial z_{i+d}} \frac{\partial g}{\partial z_i} \right)
  - Class & Signatures:
      - class SymplecticManifold:
          - __init__(spatial_dim: int, device: torch.device, dtype:
            torch.dtype): Allocates J as an invariant registered buffer of shape
            [2*d, 2*d].
          - canonical_matrix() -> torch.Tensor: Returns J.
          - hamiltonian_vector_field(grad_H: torch.Tensor) -> torch.Tensor:
              - Input: grad_H shape [B, 2*d].
              - Output: X_H = grad_H @ J.T shape [B, 2*d].
          - poisson_bracket(f: torch.Tensor, g: torch.Tensor, z: torch.Tensor)
            -> torch.Tensor:
              - Computes exact autodiff gradients:
                \nabla_z f = \frac{\partial \sum f}{\partial z} and
                \nabla_z g = \frac{\partial \sum g}{\partial z}.
              - Evaluates batch dot-product with symplectic metric:
                \text{sum}(\nabla_z f \cdot (\nabla_z g @ J^T), \text{dim}=-1, \text{keepdim}=\text{True}).
              - Input: f shape [B, 1], g shape [B, 1], z shape [B, 2*d] with
                requires_grad=True.
              - Output: [B, 1].
          - check_symplectomorphism(jacobian_map: torch.Tensor, tol: float
            = 1e-6) -> Tuple[bool, torch.Tensor]:
              - Evaluates symplectic structural drift: E = M^T J M - J.
              - Input: jacobian_map
                M = \frac{\partial \Phi_{\Delta t}(z)}{\partial z} shape
                [B, 2*d, 2*d].
              - Output: (torch.max(torch.norm(E, p='fro', dim=[-2, -1])) < tol,
                E).

3.7. dynamics/stability_memory.py

  - Purpose: Anti-catastrophic forgetting engine based on Riemannian subspace

        sensitivity Jacobian matrix of invariants with respect to model

        A \in \mathbb{R}^{K \times P}, \quad A_{k, j} = \mathbb{E}_{z \sim \mathcal{M}} \left[ \frac{\partial \{Q_k, H_\theta\}(z)}{\partial \theta_j} \right]
      - The parameter tangent space is partitioned into a protected subspace
        \mathcal{V}_{\text{prot}} = \text{span}(A^T) and a plastic subspace
        \mathcal{V}_{\text{free}} = \text{null}(A).
      - Any unconstrained gradient of a new incoming task
        \nabla_\theta L_{\text{new}} is projected onto the nullspace via the
        orthogonal projection operator:
        P_{\text{null}} = \mathbf{I}_P - A^T (A A^T + \lambda \mathbf{I}_K)^{-1} A
        \widetilde{\nabla}_\theta L = P_{\text{null}} \nabla_\theta L_{\text{new}}
      - This guarantees strictly:
        \frac{\partial \{Q_k, H_{\theta + \Delta \theta}\}}{\partial t} \approx 0 \quad \forall k \in \{1, \dots, K\}.

3.8. noether/symmetry_miner.py

  - Purpose: Neural mining of infinitesimal generators of Lie symmetries through
    continuous optimization over Poisson commutators.
  - Mathematical Operations:
      - Parametrizes a candidate conserved scalar invariant functional
        Q_\phi: \mathcal{M} \to \mathbb{R}.
      - Objective Functional (Multi-Objective Optimization):
        \mathcal{L}_{\text{Noether}}(\phi) = \mathcal{L}_{\text{comm}} + \lambda_{\text{var}} \mathcal{L}_{\text{non-triv}} + \lambda_{\text{orth}} \mathcal{L}_{\text{orth}}
        \mathcal{L}_{\text{comm}} = \mathbb{E}_{z \sim \mathcal{M}} \left[ \Big( \{Q_\phi, H_\theta\}(z) \Big)^2 \right]
        \mathcal{L}_{\text{non-triv}} = \exp\left( - \text{Var}_{z \sim \mathcal{M}}[Q_\phi(z)] \right)
        \mathcal{L}_{\text{orth}} = \left( \frac{\mathbb{E}_z [ \langle \nabla_z Q_\phi, \nabla_z H_\theta \rangle ]}{\sqrt{\mathbb{E}_z [\|\nabla_z Q_\phi\|^2]} \sqrt{\mathbb{E}_z [\|\nabla_z H_\theta\|^2]}} \right)^2
      - \mathcal{L}_{\text{comm}} drives Poisson commutation to zero.
      - \mathcal{L}_{\text{non-triv}} prevents the collapsed trivial solution
        Q_\phi(z) = \text{const}.
      - \mathcal{L}_{\text{orth}} prevents Q_\phi from simply rediscovering the
        Hamiltonian H_\theta itself.
  - Class & Signatures:
      - class LieSymmetryMiner(torch.nn.Module):
          - __init__(manifold: SymplecticManifold, hidden_dims: List[int] =

          - forward(z: torch.Tensor) -> torch.Tensor: Output Q shape [B, 1].
          - compute_loss(z_batch: torch.Tensor, H_model: HamiltonianNN) ->
            Tuple[torch.Tensor, Dict[str, float]]:

              - Output: (total_loss, metrics_dict).
