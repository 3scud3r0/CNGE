# Implement CNGE-v2: latent filtering, constrained sparse distillation and continual adapters

The v1 pipeline derives momenta from finite differences, enumerates AST candidates, uses soft symmetry-degeneracy penalties and projects gradients in parameter space. This change introduces a recommended CNGE-v2 pipeline: differential coordinate learning and an EKF, bounded functional dictionaries with constrained STLSQ, a normalized scalar-function gauge, and low-rank energy adapters. Legacy APIs remain explicitly available for compatibility; the new pipeline does not execute those four legacy heuristics.

The requested symplectic Gram–Schmidt formula divides by `uᵀJu=0`; V2 uses a positive Sobolev scalar-function gauge instead, rejects constants/energy aliases and retains integrable scalar generators. LoRA offers explicit finite activation-space protection and exact named task snapshots as distinct policies, with capacity errors and a frozen coordinate chart. It does not claim unconditional zero forgetting over unlimited tasks. The dictionary adds radial terms needed for exact Kepler recovery and supports joint homogeneous conservation constraints.

The implementation includes calibrated streaming, bounded asynchronous ingestion, Joseph-form EKF covariance updates, checkpoint roundtrips, sparse gradient distillation, CPU demos, CI and a deterministic complete-source TXT. The legacy modules and UI remain available explicitly for compatibility.

Validation: 58 tests passed; three unchanged legacy long tests were explicitly skipped in the current run. An installed wheel completed the v2 smoke demo outside the checkout. See `docs/V2_RESULTS.md` for quantitative results and executed checks and quantitative results, and `docs/V2_VALIDATION.md` for the requested acceptance criteria and their mathematical limits. CPU tests distinguish identifiable noisy full-state telemetry from ambiguous position-only images, exact sparse recovery from autonomous neural discovery, and task-conditioned retention from unrestricted activation-space claims. GPU/real-camera production operation remains unvalidated.
