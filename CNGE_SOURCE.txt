# CNGE — Continuous Neuro-Geometric Epistemic Engine

Implementação de referência executável da arquitetura neurogeométrica do anexo, em Python/PyTorch. Inclui os 22 módulos especificados, testes, demonstração científica, runtime de aprendizado online, transporte WebSocket e uma interface de inspeção em canvas.

**Estado:** pesquisa/desenvolvimento. As metas de descoberta autônoma geral, retenção perfeita, prova física, desempenho GPU e operação de produção ainda não estão demonstradas. Consulte [limites e correspondência com o pedido](docs/VALIDATION.md).

## Instalação

Python 3.11+ (validado localmente com Python 3.12). CPU não requer GPU, câmera, serviços externos ou credenciais:

```bash
cd /workspace/CNGE
python -m venv .venv
.venv/bin/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pip check
```

Em uma máquina CUDA, instale primeiro a distribuição de PyTorch adequada ao driver usando as instruções oficiais do PyTorch, e selecione `EngineConfig(device="cuda")`. Não presuma disponibilidade de GPU. Cada tarefa cloud já é isolada: use o checkout existente, sem criar worktrees.

## Executar e verificar

```bash
.venv/bin/cnge-demo --steps 1000 --output artifacts/demo.json
.venv/bin/pytest -q
.venv/bin/pytest --long -m long -q  # três testes de 50.000 passos, execução mais demorada
.venv/bin/ruff check cnge_engine tests tools
.venv/bin/ruff format --check cnge_engine tests tools
.venv/bin/python -m build
```

A demonstração integra o oscilador harmônico isotrópico 3D, verifica um invariante analítico conhecido, sintetiza `L_z = q_x p_y - q_y p_x`, verifica a expressão em pontos separados e a registra na gramática. O relatório distingue esse exercício de uma descoberta neural autônoma.

## Interface e aprendizado online

```bash
.venv/bin/python tools/live_demo.py
# Execução finita, útil para smoke test:
.venv/bin/python tools/live_demo.py --steps 100
```

O processo inicia HTTP na porta 8081 e WebSocket na 8080, ambos em loopback. Para acesso local, abra o arquivo servido pelo HTTP no navegador da mesma máquina. A interface mostra `(q₁,q₂,p₁)`, métricas, candidatos e permite perturbações e restrição rotacional xy. Essa é uma projeção visual, não uma transformação simplética em 3D. Os processos não sobrevivem a snapshots: reinicie o comando quando necessário. `Ctrl+C` fecha o runtime e os servidores. Não exponha esse servidor sem autenticação e uma configuração de implantação própria.

Para outros sensores, forneça um iterador assíncrono de coordenadas `[d]` ao método `start_epistemic_runtime(source)` e aguarde a tarefa retornada. `stop()` cancela e coleta tarefas. A fonte deve ter período uniforme `integrator_dt` e massa constante conhecida para que a aproximação `p = m dq/dt` seja apropriada. Uma mudança de coordenadas observada não necessariamente corresponde a um impulso físico.

```python
import asyncio
from cnge_engine import EngineConfig
from cnge_engine.streaming.asynchronous_orchestrator import EpistemicContinuousOrchestrator

async def observations():
    for q in ([1., 0.], [.99995, .01], [.9998, .02]):
        yield q

async def main():
    engine = EpistemicContinuousOrchestrator(EngineConfig(spatial_dim=2))
    try:
        await engine.start_epistemic_runtime(observations())
        print(engine.metrics)
    finally:
        await engine.stop()

asyncio.run(main())
```

O runtime realiza atualização Hamiltoniana por SGD com gradiente projetado, mineração Noether por Adam, replay periódico, verificação empírica e compilação condicional. A mineração e as operações tensoriais são serializadas numa tarefa cooperativa para evitar corridas nos parâmetros; não se afirma execução concorrente em streams CUDA. A busca simbólica pode bloquear brevemente o loop. Eventos externos têm fila limitada e quadros são descartados em favor do mais recente para clientes lentos.

### Integrações opcionais

- **Embeddings:** `pip install -e '.[semantic]'`. `FoundationEmbeddingBridge` carrega um modelo Sentence Transformers explicitamente; o download requer acesso ao Hugging Face e seus hosts de armazenamento. Não ocorre na importação do pacote. O adaptador foi testado com backend injetado; o modelo remoto não foi baixado. A projeção contrastiva precisa de pares científicos rotulados antes de uso semântico significativo.
- **Câmera:** `pip install -e '.[camera]'`. `ContinuousSensorStream.capture(coordinate_extractor)` requer um dispositivo e uma função que transforme frames em coordenadas físicas calibradas. O código não interpreta pixels como posições ou inventa calibração.
- **Semântica:** a tradução de restrições suporta explicitamente rotação no plano xy. Prompts arbitrários são rejeitados; a explicação apresenta a expressão e o estado empírico, sem inventar citações ou provas.

from dataclasses import dataclass, field

import numpy as np


@dataclass(frozen=True)
class ASTNode:
    op: str
    children: tuple = ()
    value: float | int | None = None

    def __post_init__(self):
        object.__setattr__(self, "children", tuple(self.children))
        arity = {
            "const": 0,
            "var": 0,
            "+": 2,
            "-": 2,
            "*": 2,
            "/": 2,
            "sin": 1,
            "cos": 1,
            "exp": 1,
            "ln": 1,
            "square": 1,
            "sqrt": 1,
        }
        if self.op not in arity or len(self.children) != arity[self.op]:
            raise ValueError("unknown operator or invalid arity")
        if self.op == "const" and (self.value is None or not np.isfinite(self.value)):
            raise ValueError("constant must be finite")
        if self.op == "var" and (not isinstance(self.value, int) or self.value < 0):
            raise ValueError("variable requires a nonnegative integer index")

    def evaluate(self, z):
        z = np.asarray(z)
        if self.op == "const":
            return np.full(z.shape[:-1], self.value, dtype=float)
        if self.op == "var":
            return z[..., self.value]
        args = [c.evaluate(z) for c in self.children]
        operations = {
            "+": np.add,
            "-": np.subtract,
            "*": np.multiply,
            "/": np.divide,
            "sin": np.sin,
            "cos": np.cos,
            "exp": np.exp,
            "ln": np.log,
            "square": np.square,
            "sqrt": np.sqrt,
        }
        # Invalid domains remain invalid: no protected division/log that changes the equation.
        with np.errstate(all="ignore"):
            return operations[self.op](*args)

    def to_latex(self):
        if self.op == "const":
            return f"{self.value:g}"
        if self.op == "var":
            return f"z_{{{self.value}}}"
        c = [child.to_latex() for child in self.children]
        if self.op in ("+", "-", "*"):
            symbol = r"\cdot" if self.op == "*" else self.op
            return f"({c[0]} {symbol} {c[1]})"
        if self.op == "/":
            return rf"\frac{{{c[0]}}}{{{c[1]}}}"
        if self.op == "square":
            return f"({c[0]})^2"
        if self.op == "sqrt":
            return rf"\sqrt{{{c[0]}}}"
        return rf"\{self.op}({c[0]})"

    def complexity(self):
        return 1 + sum(c.complexity() for c in self.children)

    def depth(self):
        return 1 + max((c.depth() for c in self.children), default=0)


@dataclass
class ASTGrammar:
    variable_count: int
    constants: tuple = (0.0, 1.0, -1.0, 0.5)
    binary_ops: tuple = ("+", "-", "*", "/")
    unary_ops: tuple = ("sin", "cos", "exp", "ln", "square", "sqrt")
    registered: dict = field(default_factory=dict)

    def __post_init__(self):
        if self.variable_count < 1:
            raise ValueError("variable_count must be positive")

    def terminals(self):
        return (
            [ASTNode("var", value=i) for i in range(self.variable_count)]
            + [ASTNode("const", value=c) for c in self.constants]
            + list(self.registered.values())
        )

from .ast_grammar import ASTNode


class DynamicOperatorRegistry:
    def __init__(self, base_grammar):
        self.grammar = base_grammar

    def register_crystallized_invariant(self, symbolic_node: ASTNode, latex_name: str):
        if not latex_name.strip():
            raise ValueError("operator name must be nonempty")

        def validate(node):
            if node.op == "var" and node.value >= self.grammar.variable_count:
                raise ValueError("operator references an out-of-domain variable")
            for child in node.children:
                validate(child)

        validate(symbolic_node)
        if (
            latex_name in self.grammar.registered
            and self.grammar.registered[latex_name] != symbolic_node
        ):
            raise ValueError("operator name already registered")
        # Preserve the expanded node's complexity; no cost-free macro compression.
        self.grammar.registered[latex_name] = symbolic_node

    def get_active_grammar(self):
        return self.grammar

import itertools
from dataclasses import dataclass

import numpy as np

from .ast_grammar import ASTNode


@dataclass(frozen=True)
class Candidate:
    node: ASTNode
    mse: float
    r2: float


class ParetoSymbolicCompiler:
    """Bounded search plus quadratic least squares. No global-optimum guarantee."""

    def __init__(self, grammar, max_depth=6, beam_width=64, mdl_weight=0.05):
        if max_depth < 1 or beam_width < 1 or mdl_weight < 0:
            raise ValueError("invalid search budget")
        self.grammar, self.max_depth, self.beam_width = grammar, max_depth, beam_width
        self.mdl_weight = mdl_weight
        self.frontier = []

    def compile(self, target_eval_fn, z_domain, r2_target=0.9999):
        z = np.asarray(z_domain, dtype=float)
        if (
            z.ndim != 2
            or z.shape[1] != self.grammar.variable_count
            or len(z) < 2
            or not np.isfinite(z).all()
        ):
            raise ValueError("invalid symbolic domain")
        y = np.asarray(target_eval_fn(z), dtype=float).reshape(-1)
        if len(y) != len(z) or not np.isfinite(y).all() or not 0 <= r2_target <= 1:
            raise ValueError("invalid target evaluations or R2 target")
        variance = np.mean((y - y.mean()) ** 2)
        seen, candidates = set(), []

        def add(node):
            if node.depth() > self.max_depth or node in seen:
                return
            seen.add(node)
            values = node.evaluate(z)
            if not np.isfinite(values).all():
                return
            with np.errstate(over="ignore"):
                mse = float(np.mean((values - y) ** 2))
            if not np.isfinite(mse):
                return
            r2 = 1 - mse / variance if variance > 1e-24 else float(mse < 1e-24)
            candidates.append(Candidate(node, mse, r2))

        terminals = self.grammar.terminals()
        for node in terminals:
            add(node)
        # Fit sparse quadratic signatures; all retained coefficients are explicit AST constants.
        variables = [ASTNode("var", value=i) for i in range(z.shape[1])]
        features = [ASTNode("const", value=1.0), *variables]
        features += [
            ASTNode("*", (a, b)) for a, b in itertools.combinations_with_replacement(variables, 2)
        ]
        coefficients = np.linalg.lstsq(
            np.stack([f.evaluate(z) for f in features], 1), y, rcond=None
        )[0]
        terms = []
        for coefficient, feature in zip(coefficients, features):
            if abs(coefficient) < 1e-9:
                continue
            rounded = round(float(coefficient), 10)
            term = (
                feature
                if abs(rounded - 1) < 1e-9
                else ASTNode("*", (ASTNode("const", value=rounded), feature))
            )
            terms.append(term)
        if terms:
            node = terms[0]
            for term in terms[1:]:
                # Emit subtraction for negative unit factors, preserving angular-momentum structure.
                if (
                    term.op == "*"
                    and term.children[0].op == "const"
                    and term.children[0].value == -1
                ):
                    node = ASTNode("-", (node, term.children[1]))
                else:
                    node = ASTNode("+", (node, term))
            add(node)
        for _ in range(self.max_depth - 1):
            accurate = [c for c in candidates if c.r2 >= r2_target]
            if accurate:
                break
            beam = sorted(candidates, key=lambda c: c.mse + self.mdl_weight * c.node.complexity())[
                : self.beam_width
            ]
            for c in beam:
                for op in self.grammar.unary_ops:
                    add(ASTNode(op, (c.node,)))
                for other in terminals:
                    for op in self.grammar.binary_ops:
                        add(ASTNode(op, (c.node, other)))
                        if op in ("-", "/"):
                            add(ASTNode(op, (other, c.node)))
        ordered = sorted(candidates, key=lambda c: (c.node.complexity(), c.mse))
        self.frontier = []
        best = float("inf")
        for c in ordered:
            if c.mse < best:
                self.frontier.append(c)
                best = c.mse
        accurate = [c for c in self.frontier if c.r2 >= r2_target]
        if accurate:
            return min(accurate, key=lambda c: (c.node.complexity(), c.mse)).node
        return min(self.frontier, key=lambda c: c.mse + self.mdl_weight * c.node.complexity()).node

import torch


class PhaseTopologyAnalyzer:
    def __init__(self, manifold):
        self.manifold = manifold

    def compute_poincare_map(self, trajectory, surface_fn, chart_fn=None):
        """Positive transverse crossings, linearly interpolated in ambient coordinates.

        A user-supplied surface chart is required to return intrinsic 2d-1 coordinates.
        A general surface has no canonical coordinate that can safely be dropped.
        """
        if trajectory.ndim != 2 or len(trajectory) < 2:
            raise ValueError("expected [T,2d], T>=2")
        s = surface_fn(trajectory).reshape(-1)
        if len(s) != len(trajectory):
            raise ValueError("surface must return one value per point")
        indices = torch.where((s[:-1] < 0) & (s[1:] >= 0))[0]
        fraction = -s[indices] / (s[indices + 1] - s[indices])
        points = trajectory[indices] + fraction[:, None] * (
            trajectory[indices + 1] - trajectory[indices]
        )
        return chart_fn(points) if chart_fn else points

    def detect_attractor_dimensionality(self, trajectory):
        """Finite-sample correlation dimension, with bounded O(2048^2) memory."""
        if trajectory.ndim != 2 or len(trajectory) < 20 or not torch.isfinite(trajectory).all():
            raise ValueError("need at least 20 finite trajectory points")
        stride = max(1, (len(trajectory) + 2047) // 2048)
        distances = torch.pdist(trajectory[::stride]).double()
        distances = distances[distances > 0]
        if len(distances) < 10:
            raise ValueError("degenerate trajectory")
        lo, hi = torch.quantile(
            distances, torch.tensor([0.05, 0.5], device=distances.device, dtype=distances.dtype)
        )
        if hi <= lo:
            raise ValueError("no usable scale interval")
        radii = torch.exp(torch.linspace(lo.log(), hi.log(), 16, device=lo.device))
        counts = (distances[:, None] < radii).double().mean(0)
        valid = (counts > 0) & (counts < 1)
        if valid.sum() < 3:
            raise ValueError("insufficient correlation scales")
        x, y = radii[valid].log(), counts[valid].log()
        return float(((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean()) ** 2).sum())

    @staticmethod
    def pullback_metric(flow_fn, z):
        jacobians = torch.stack([torch.func.jacrev(flow_fn)(point) for point in z])
        return jacobians.transpose(-1, -2) @ jacobians

"""Reproducible oscillator -> conservation -> symbolic registry demo, no model downloads."""

import argparse
import json
from pathlib import Path

import numpy as np
import torch

from .crystallization.ast_grammar import ASTGrammar
from .crystallization.dynamic_operator_registry import DynamicOperatorRegistry

from .math_core.integrators import Yoshida4thIntegrator
from .math_core.symplectic import SymplecticManifold

def run_demo(steps=1000, seed=7):
    if steps < 2:
        raise ValueError("steps must be >=2")
    generator = torch.Generator().manual_seed(seed)
    manifold = SymplecticManifold(3, dtype=torch.float64)
    z = torch.randn(8, 6, generator=generator, dtype=torch.float64)
    # Keep normalization away from zero for this relative-drift demonstration.
    z[:, 0], z[:, 1], z[:, 3], z[:, 4] = 1.0, 0.0, 0.0, 1.0
    integrator = Yoshida4thIntegrator()
    history = [z]
    for _ in range(steps):
        q, p = integrator.step_separable(*z.chunk(2, -1), lambda q: q, lambda p: p, 0.01)
        z = torch.cat((q, p), -1)
        history.append(z)

    def angular(t):
        return t[:, :1] * t[:, 4:5] - t[:, 1:2] * t[:, 3:4]

    valid, drift = ConservationVerifier(manifold, tolerance=1e-8).verify_trajectory_invariance(
        angular, torch.stack(history, 1)
    )
    samples = np.random.default_rng(seed).normal(size=(256, 6))
    target = lambda x: x[:, 0] * x[:, 4] - x[:, 1] * x[:, 3]
    grammar = ASTGrammar(6)
    compiler = ParetoSymbolicCompiler(grammar)
    node = compiler.compile(target, samples)
    registry = DynamicOperatorRegistry(grammar)

import torch
from torch import nn

from ..math_core.symplectic import scalar_gradient


class SmoothSoftplus(nn.Module):
    """Stable softplus without the piecewise linear threshold of nn.Softplus."""

    def __init__(self, beta=5.0):
        super().__init__()
        if beta <= 0:
            raise ValueError("beta must be positive")
        self.beta = beta

    def forward(self, x):
        return torch.logaddexp(torch.zeros_like(x), self.beta * x) / self.beta


def smooth_mlp(input_dim, hidden_dims, beta=5.0):
    layers = []
    previous = input_dim
    for width in hidden_dims:
        layers.extend((nn.Linear(previous, width), SmoothSoftplus(beta)))
        previous = width
    return nn.Sequential(*layers, nn.Linear(previous, 1))


class HamiltonianNN(nn.Module):
    def __init__(self, manifold, hidden_dims=(128, 128, 128), beta=5.0):
        super().__init__()
        self.manifold = manifold
        self.network = smooth_mlp(2 * manifold.spatial_dim, hidden_dims, beta).to(manifold.J)

    def forward(self, z):
        return self.network(z)

    def predict_vector_field(self, z):
        with torch.enable_grad():
            if not z.requires_grad:
                z = z.detach().requires_grad_(True)
            return self.manifold.hamiltonian_vector_field(scalar_gradient(self(z), z))

    def trajectory_loss(self, z_observed, dt):
        if dt <= 0 or z_observed.ndim != 3 or z_observed.shape[1] != 2:
            raise ValueError("expected [B,2,2d] and positive dt")
        midpoint = z_observed.mean(1)
        observed = (z_observed[:, 1] - z_observed[:, 0]) / dt
        return ((self.predict_vector_field(midpoint) - observed) ** 2).sum(-1).mean()

class LagrangianNN(nn.Module):
    def __init__(self, spatial_dim, hidden_dims=(128, 128)):
        super().__init__()
        self.spatial_dim = spatial_dim
        self.network = smooth_mlp(2 * spatial_dim, hidden_dims)

    def forward(self, q, q_dot):
        return self.network(torch.cat((q, q_dot), -1))

    def compute_acceleration(self, q, q_dot):
        def scalar(qi, vi):
            return self(qi[None], vi[None]).sum()

        rows = []
        for qi, vi in zip(q, q_dot):
            dLq = torch.func.grad(scalar, argnums=0)(qi, vi)
            momentum = torch.func.grad(scalar, argnums=1)
            mass = torch.func.jacrev(momentum, argnums=1)(qi, vi)
            mixed = torch.func.jacrev(momentum, argnums=0)(qi, vi)
            # Singular/ill-conditioned learned mass matrices must not be silently inverted.
            if not torch.isfinite(mass).all() or torch.linalg.cond(mass).detach() > 1e10:
                raise RuntimeError("singular or ill-conditioned Lagrangian mass matrix")
            rows.append(torch.linalg.solve(mass, dLq - mixed @ vi))
        return torch.stack(rows)

import torch


class SymplecticSubspaceProtector:
    """Low-rank Euclidean parameter projection; preservation is local, not a theorem of retention."""

    def __init__(self, parameter_dim, damping=1e-4):
        if parameter_dim < 1 or damping < 0:
            raise ValueError("invalid projection dimensions or damping")
        self.parameter_dim, self.damping = parameter_dim, damping
        self.rows = []

    def register_invariant(self, Q_invariant_fn, H_model, validation_samples):
        z = validation_samples.detach().requires_grad_(True)
        residual = H_model.manifold.poisson_bracket(Q_invariant_fn(z), H_model(z), z).mean()
        params = [p for p in H_model.parameters() if p.requires_grad]
        if sum(p.numel() for p in params) != self.parameter_dim:
            raise ValueError("parameter dimension mismatch")
        grads = torch.autograd.grad(residual, params, allow_unused=True)
        self.rows.append(
            torch.cat(
                [
                    (torch.zeros_like(p) if g is None else g).reshape(-1)
                    for p, g in zip(params, grads)
                ]
            ).detach()
        )

    def project_gradient(self, raw_gradient):
        if raw_gradient.shape != (self.parameter_dim,):
            raise ValueError("expected a flat parameter gradient")
        if not self.rows:
            return raw_gradient.clone()
        A = torch.stack(self.rows).to(raw_gradient)
        if self.damping == 0:
            return raw_gradient - torch.linalg.pinv(A) @ (A @ raw_gradient)
        gram = A @ A.T + self.damping * torch.eye(len(A), device=A.device, dtype=A.dtype)
        return raw_gradient - A.T @ torch.linalg.solve(gram, A @ raw_gradient)

import math
from abc import ABC, abstractmethod

import torch


class SymplecticIntegrator(ABC):
    @abstractmethod
    def step(self, z_t, vector_field_fn, dt):
        raise NotImplementedError


def _validate_dt(dt):
    if not math.isfinite(dt):
        raise ValueError("dt must be finite")


class ImplicitMidpointIntegrator(SymplecticIntegrator):
    """Differentiable fixed-point solve; raises instead of accepting nonconvergence."""

    def __init__(self, max_iters=20, tol=1e-12):
        if max_iters < 1 or tol <= 0:
            raise ValueError("invalid solver controls")
        self.max_iters, self.tol = max_iters, tol

    def step(self, z_t, vector_field_fn, dt):
        _validate_dt(dt)
        estimate = z_t
        for _ in range(self.max_iters):
            updated = z_t + dt * vector_field_fn((z_t + estimate) / 2)
            residual = (updated - estimate).detach().abs().max()
            if not torch.isfinite(updated).all():
                raise RuntimeError("nonfinite midpoint iterate")
            # A precision floor is necessary for float32; float64 retains the requested tolerance.
            threshold = max(
                self.tol,
                4 * torch.finfo(z_t.dtype).eps * max(1.0, float(updated.detach().abs().max())),
            )
            estimate = updated
            if residual <= threshold:
                return estimate
        raise RuntimeError("implicit midpoint did not converge; reduce dt or increase max_iters")


class Yoshida4thIntegrator(SymplecticIntegrator):
    """Fourth order composition for explicitly separable H=T(p)+V(q)."""

    def step(self, z_t, vector_field_fn, dt):
        raise ValueError("Yoshida requires explicit grad_V_fn and grad_T_fn; use step_separable")

    def step_separable(self, q_t, p_t, grad_V_fn, grad_T_fn, dt):
        _validate_dt(dt)
        w1 = 1 / (2 - 2 ** (1 / 3))
        w0 = -(2 ** (1 / 3)) * w1
        q, p = q_t, p_t
        for weight in (w1, w0, w1):
            p = p - dt * weight / 2 * grad_V_fn(q)
            q = q + dt * weight * grad_T_fn(p)
            p = p - dt * weight / 2 * grad_V_fn(q)
        return q, p

import torch


class LieAlgebraEngine:
    @staticmethod
    def lie_bracket_fields(X_fn, Y_fn, z):
        _, dy_x = torch.autograd.functional.jvp(Y_fn, z, X_fn(z), create_graph=True)
        _, dx_y = torch.autograd.functional.jvp(X_fn, z, Y_fn(z), create_graph=True)
        return dy_x - dx_y

    def structure_constants(self, basis_fields, z_samples):
        if not basis_fields:
            raise ValueError("empty basis")
        design = torch.stack([fn(z_samples).reshape(-1) for fn in basis_fields], -1)
        rows = []
        for x in basis_fields:
            rows.append(
                torch.stack(
                    [
                        torch.linalg.lstsq(
                            design, self.lie_bracket_fields(x, y, z_samples).reshape(-1, 1)
                        ).solution[:, 0]
                        for y in basis_fields
                    ]
                )
            )
        return torch.stack(rows)

    @staticmethod
    def killing_residual(X_fn, metric_fn, z):
        """Pointwise Lie derivative of a metric, shape [B,n,n]."""

        def point(x):
            X = X_fn(x[None])[0]
            g = metric_fn(x[None])[0]
            jac = torch.func.jacrev(lambda t: X_fn(t[None])[0])(x)
            dg = torch.func.jacrev(lambda t: metric_fn(t[None])[0])(x)
            return torch.einsum("ijk,k->ij", dg, X) + jac.T @ g + g @ jac

        return torch.stack([point(x) for x in z])

import torch
from torch import nn


def scalar_gradient(value, z):
    """Gradient of independent scalar evaluations, including constant functions."""
    if not value.requires_grad:
        return z * 0
    grad = torch.autograd.grad(
        value.sum(), z, create_graph=True, retain_graph=True, allow_unused=True
    )[0]
    return z * 0 if grad is None else grad


class SymplecticManifold(nn.Module):
    def __init__(self, spatial_dim, device="cpu", dtype=torch.float32):
        super().__init__()
        if spatial_dim < 1:
            raise ValueError("spatial_dim must be positive")
        self.spatial_dim = spatial_dim
        eye = torch.eye(spatial_dim, device=device, dtype=dtype)
        zero = torch.zeros_like(eye)
        self.register_buffer(
            "J", torch.cat((torch.cat((zero, eye), 1), torch.cat((-eye, zero), 1)), 0)
        )

    def canonical_matrix(self):
        return self.J

    def hamiltonian_vector_field(self, grad_H):
        if grad_H.shape[-1] != self.J.shape[0]:
            raise ValueError("incorrect phase dimension")
        return grad_H @ self.J.T

    def poisson_bracket(self, f, g, z):
        if not z.requires_grad:
            raise ValueError("z must require gradients")
        return (scalar_gradient(f, z) * self.hamiltonian_vector_field(scalar_gradient(g, z))).sum(
            -1, keepdim=True
        )

    def check_symplectomorphism(self, jacobian_map, tol=1e-6):
        error = jacobian_map.transpose(-1, -2) @ self.J @ jacobian_map - self.J
        return bool(torch.linalg.matrix_norm(error).max() < tol), error

import math

import torch


class ConservationVerifier:
    """Empirical relative trajectory drift; confidence bounds require independent bounded samples."""

    def __init__(self, manifold, tolerance=1e-4, confidence=0.999):
        if tolerance <= 0 or not 0 < confidence < 1:
            raise ValueError("invalid verification settings")
        self.manifold, self.tolerance, self.confidence = manifold, tolerance, confidence

    def verify_trajectory_invariance(self, Q_fn, trajectories):
        if trajectories.ndim != 3 or trajectories.shape[1] < 2 or not trajectories.numel():
            raise ValueError("expected nonempty [B,T,2d], T>=2")
        values = Q_fn(trajectories.reshape(-1, trajectories.shape[-1])).reshape(
            *trajectories.shape[:2], -1
        )
        initial = values[:, :1]
        drift = ((values - initial).abs() / (initial.abs() + torch.finfo(values.dtype).eps)).max()
        metric = float(drift.detach())
        return math.isfinite(metric) and metric < self.tolerance, metric

    def bounded_failure_upper_bound(self, failures, sample_count):
        """Hoeffding upper bound on Bernoulli failure rate for IID trajectories, not timesteps."""
        if not 0 <= failures <= sample_count or sample_count < 1:
            raise ValueError("invalid sample counts")
        return min(
            1.0,
            failures / sample_count
            + math.sqrt(math.log(1 / (1 - self.confidence)) / (2 * sample_count)),
        )

    def _learn(self, pairs):
        self.h_optimizer.zero_grad(set_to_none=True)
        loss = self.hamiltonian.trajectory_loss(pairs, self.config.integrator_dt)
        if self.rotation_constraint:
            z = pairs[:, 0].detach().requires_grad_(True)
            d = self.config.spatial_dim
            L = z[:, :1] * z[:, d + 1 : d + 2] - z[:, 1:2] * z[:, d : d + 1]
            loss = loss + self.manifold.poisson_bracket(L, self.hamiltonian(z), z).square().mean()
        loss.backward()
        params = list(self.hamiltonian.parameters())
        flat = torch.cat(
            [(torch.zeros_like(p) if p.grad is None else p.grad).reshape(-1) for p in params]
        )
        projected = self.protector.project_gradient(flat)
        offset = 0
        for p in params:
            p.grad = projected[offset : offset + p.numel()].reshape_as(p).clone()
            offset += p.numel()
        self.h_optimizer.step()
        self.q_optimizer.zero_grad(set_to_none=True)
        mining_loss, metrics = self.miner.compute_loss(pairs[:, 0], self.hamiltonian)
        gradients = torch.autograd.grad(mining_loss, self.miner.parameters())
        for p, grad in zip(self.miner.parameters(), gradients):
            p.grad = grad
        self.q_optimizer.step()
        self.metrics = {
            "dynamics_loss": float(loss.detach()),
            "mining_loss": float(mining_loss.detach()),
            **metrics,
        }

    def _try_discovery(self):
        if len(self.buffer) < 32:
            return
        samples = torch.cat(list(self.buffer))
        training, heldout = samples[::2], samples[1::2]
        z = heldout.detach().requires_grad_(True)
        Q = self.miner(z)
        bracket = self.manifold.poisson_bracket(Q, self.hamiltonian(z), z)
        if (
            float(Q.detach().var()) < self.config.min_invariant_variance
            or float(bracket.detach().abs().max()) >= self.config.poisson_threshold
        ):
            return
        trajectory = samples.unsqueeze(0)
        valid, drift = self.verifier.verify_trajectory_invariance(self.miner, trajectory)
        if not valid:
            return

        def target(array):
            with torch.no_grad():
                tensor = torch.as_tensor(array, device=self.config.device, dtype=self.config.dtype)
                return self.miner(tensor).cpu().numpy().reshape(-1)

        node = self.compiler.compile(target, training.cpu().numpy())
        actual = target(heldout.cpu().numpy())
        predicted = node.evaluate(heldout.cpu().numpy())
        variance = np.var(actual)
        r2 = 1 - np.mean((predicted - actual) ** 2) / max(float(variance), 1e-24)
        if not np.isfinite(r2) or r2 < 0.9999 or node in self.registry.grammar.registered.values():
            return
        self.discovery_counter += 1
        name = f"Q_{self.discovery_counter}"
        self.registry.register_crystallized_invariant(node, name)
        self.protector.register_invariant(self.miner, self.hamiltonian, heldout)
        self.discovery_reports.append(
            {
                "name": name,
                "latex": node.to_latex(),
                "empirical_drift": drift,
                "heldout_r2": float(r2),
                "status": "empirical candidate; not a physical proof",
            }
        )
        # Bound metadata and protected subspace growth in a continuous process.
        self.discovery_reports = self.discovery_reports[-32:]
        self.protector.rows = self.protector.rows[-32:]
        if len(self.registry.grammar.registered) > 32:
            self.registry.grammar.registered.pop(next(iter(self.registry.grammar.registered)))

    async def process_observation(self, coordinates):
        self._apply_interventions()
        q = torch.as_tensor(coordinates, device=self.config.device, dtype=self.config.dtype)
        if q.ndim == 1:
            q = q[None]
        if q.shape != (1, self.config.spatial_dim):
            raise ValueError("runtime accepts one [d] or [1,d] sensor observation at a time")
        state = self.filter.update_and_extract_phase_point(q) + self.offset
        # First finite-difference velocity is undefined; skip it for training.
        if self.filter.previous is not None and self.updates == 0 and self.previous is None:
            self.updates += 1
            return state
        if self.previous is not None:
            pair = torch.stack((self.previous, state), 1)
            recent = list(self.buffer)[-31:] + [state.detach()]
            if len(recent) > 1:
                replay = torch.cat(recent)
                self._learn(torch.stack((replay[:-1], replay[1:]), 1))
            else:
                self._learn(pair)
        self.previous = state.detach()
        self.buffer.append(state.detach())
        self.updates += 1
        if self.config.integrator_type == "yoshida4":
            q1, p1 = Yoshida4thIntegrator().step_separable(
                *state.chunk(2, -1), *self.separable_gradients, self.config.integrator_dt
            )
            prediction = torch.cat((q1, p1), -1)
        else:
            prediction = self.integrator.step(
                state, self.hamiltonian.predict_vector_field, self.config.integrator_dt
            )
        if self.updates % self.config.discovery_interval == 0:
            self._try_discovery()
        if time.monotonic() >= self.next_replay:
            states = torch.cat(list(self.buffer))
            if len(states) >= 2:
                self._learn(torch.stack((states[:-1], states[1:]), 1))
            self.next_replay = time.monotonic() + self.config.memory_replay_interval_secs
        if self.canvas is not None and time.monotonic() - self._last_frame >= 1 / 60:
            vertices = SymplecticPhaseProjector(self.config.spatial_dim).project_to_3d(
                state[:, None]
            )
            await self.canvas.broadcast_phase_frame(
                {
                    "vertices": vertices.tolist(),
                    "metrics": self.metrics,
                    "discoveries": self.discovery_reports,
                }
            )
            self._last_frame = time.monotonic()
        return prediction.detach()

    async def _consume(self, source):
        async for coordinates in source:
            await self.process_observation(coordinates)
            await asyncio.sleep(0)

    def start_epistemic_runtime(self, source):
        if any(not task.done() for task in self.tasks):
            raise RuntimeError("runtime already active")
        self.tasks = [asyncio.create_task(self._consume(source), name="cnge-assimilation")]
        return self.tasks[0]

    async def stop(self):
        for task in self.tasks:
            if not task.done():
                task.cancel()
        results = await asyncio.gather(*self.tasks, return_exceptions=True)
        self.tasks = []
        for result in results:
            if isinstance(result, Exception):
                raise result

import asyncio
from collections import deque

import torch


class ContinuousSensorStream:
    """Bounded telemetry buffer. Camera frames require an explicit frame-to-coordinate extractor."""

    def __init__(self, source_id, target_fps=60, capacity=4096):
        if target_fps <= 0 or capacity < 1:
            raise ValueError("invalid stream controls")
        self.source_id, self.target_fps = source_id, target_fps
        self.buffer = deque(maxlen=capacity)

    def push(self, coordinates):
        value = torch.as_tensor(coordinates).detach().clone()
        if value.ndim != 1 or not torch.isfinite(value).all():
            raise ValueError("coordinates must be a finite vector")
        if self.buffer and value.shape != self.buffer[-1].shape:
            raise ValueError("coordinate dimension changed")
        self.buffer.append(value)

    def get_state_buffer(self, window_size):
        if not 0 < window_size <= len(self.buffer):
            raise ValueError("insufficient samples or invalid window")
        return torch.stack(list(self.buffer)[-window_size:])

    async def capture(self, coordinate_extractor):
        try:
            import cv2
        except ImportError as exc:
            raise RuntimeError("install cnge-engine[camera] for camera capture") from exc
        capture = cv2.VideoCapture(self.source_id)
        try:
            if not capture.isOpened():
                raise RuntimeError("camera source unavailable")
            while True:
                ok, frame = await asyncio.to_thread(capture.read)
                if not ok:
                    break
                self.push(coordinate_extractor(frame))
                await asyncio.sleep(1 / self.target_fps)
        finally:
            capture.release()

import torch


class OnlineSymplecticStateFilter:
    """EMA finite differences with explicit constant mass; canonical only for that model."""

    def __init__(self, spatial_dim, dt, mass=1.0, smoothing=1.0):
        if spatial_dim < 1 or dt <= 0 or mass <= 0 or not 0 < smoothing <= 1:
            raise ValueError("invalid filter configuration")
        self.spatial_dim, self.dt, self.mass, self.smoothing = spatial_dim, dt, mass, smoothing
        self.previous = self.velocity = None

    def update_and_extract_phase_point(self, q_observed):
        if (
            q_observed.ndim != 2
            or q_observed.shape[-1] != self.spatial_dim
            or not q_observed.is_floating_point()
            or not torch.isfinite(q_observed).all()
        ):
            raise ValueError("expected finite floating [B,d] coordinates")
        q = q_observed.detach()
        if self.previous is not None and (
            self.previous.shape != q.shape
            or self.previous.device != q.device
            or self.previous.dtype != q.dtype
        ):
            raise ValueError("reset filter before changing batch/device/dtype")
        velocity = torch.zeros_like(q) if self.previous is None else (q - self.previous) / self.dt
        self.velocity = (
            velocity
            if self.velocity is None
            else self.smoothing * velocity + (1 - self.smoothing) * self.velocity
        )
        self.previous = q.clone()
        return torch.cat((q, self.mass * self.velocity), -1)

    def reset(self):
        self.previous = self.velocity = None

import asyncio
import inspect
import json

from websockets.asyncio.server import serve
from websockets.exceptions import ConnectionClosed


class InteractiveCanvasServer:
    """Loopback WebSocket transport, bounded messages and latest-frame delivery."""

    def __init__(self, port=8080, host="127.0.0.1"):
        self.port, self.host = port, host
        self.clients = {}
        self.callbacks = []
        self.server = None

    async def start(self):
        if self.server is not None:
            raise RuntimeError("server already started")
        self.server = await serve(
            self._handler,
            self.host,
            self.port,
            max_size=65536,
            max_queue=16,
            origins=[
                None,
                f"http://{self.host}:{self.port + 1}",
                f"http://localhost:{self.port + 1}",
            ],
        )
        self.port = self.server.sockets[0].getsockname()[1]
        return self

    async def _handler(self, socket):
        queue = asyncio.Queue(maxsize=1)
        self.clients[socket] = queue

        async def send():
            while True:
                await socket.send(await queue.get())

        sender = asyncio.create_task(send())
        try:
            async for message in socket:
                try:
                    packet = json.loads(message)
                    if not isinstance(packet, dict):
                        raise TypeError("interaction must be an object")
                    for callback in self.callbacks:
                        result = callback(packet)
                        if inspect.isawaitable(result):
                            await result
                except (ValueError, TypeError, KeyError, asyncio.QueueFull) as exc:
                    await socket.send(json.dumps({"error": str(exc)}))
        except ConnectionClosed:
            pass
        finally:
            self.clients.pop(socket, None)
            sender.cancel()
            await asyncio.gather(sender, return_exceptions=True)

    async def broadcast_phase_frame(self, frame_data):
        message = json.dumps(frame_data, allow_nan=False)
        for queue in tuple(self.clients.values()):
            if queue.full():
                queue.get_nowait()
            queue.put_nowait(message)

    def on_user_interaction(self, callback):
        self.callbacks.append(callback)

    async def close(self):
        if self.server:
            self.server.close()
            await self.server.wait_closed()
            self.server = None

import torch


class SymplecticPhaseProjector:
    """Display slice only: odd-dimensional 3D space cannot preserve a symplectic form."""

    def __init__(self, spatial_dim):
        self.spatial_dim = spatial_dim

    def project_to_3d(self, z_trajectories, projection_plane="canonical_canonical"):
        if (
            projection_plane != "canonical_canonical"
            or z_trajectories.shape[-1] != 2 * self.spatial_dim
        ):
            raise ValueError("unsupported projection or wrong phase dimension")
        d = self.spatial_dim
        if d == 1:
            points = torch.stack(
                (
                    z_trajectories[..., 0],
                    z_trajectories[..., 1],
                    torch.zeros_like(z_trajectories[..., 0]),
                ),
                -1,
            )
        else:
            points = z_trajectories[..., [0, 1, d]]
        return points.detach().cpu().numpy()

SYSTEM ARCHITECTURE & MATHEMATICAL SPECIFICATION

Continuous Neuro-Geometric Epistemic Engine (CNGE)

A Production-Ready, Autonomous Scientific Discovery Architecture

1. MATHEMATICAL FORMALISM & SYSTEM FOUNDATIONS

The engine models physical and abstract dynamic phenomena on an unconstrained,
finite-dimensional, smooth canonical symplectic phase space manifold
\mathcal{M} = T^*Q \cong \mathbb{R}^{2d}, parametrized by generalized canonical
coordinates:
z = \begin{bmatrix} q \\ p \end{bmatrix} \in \mathbb{R}^{2d}, \quad q \in \mathbb{R}^d \text{ (configuration)}, \quad p \in \mathbb{R}^d \text{ (conjugate momentum)}

1.1. Differential Geometric Invariants

The manifold is equipped with a closed, non-degenerate, differential 2-form (the
canonical symplectic form) \omega \in \Omega^2(\mathcal{M}):
\omega = \sum_{i=1}^d dq^i \wedge dp^i \iff \omega(u, v) = u^T J v, \quad \forall u, v \in T_z\mathcal{M}
where J \in \text{Sp}(2d, \mathbb{R}) is the canonical skew-symmetric symplectic
matrix:
J = \begin{bmatrix} \mathbf{0}_d & \mathbf{I}_d \\ -\mathbf{I}_d & \mathbf{0}_d \end{bmatrix}, \quad J^T = -J = J^{-1}, \quad \det(J) = 1, \quad J^2 = -\mathbf{I}_{2d}

1.2. Hamiltonian Dynamics & Symplectomorphism Flow

Given a continuously differentiable parameterized energy functional
H_\theta: \mathcal{M} \to \mathbb{R}, the temporal evolution of any system state
obeys Hamilton's canonical vector field X_H \in \mathfrak{X}(\mathcal{M}):
\dot{z}(t) = X_H(z(t)) = J \nabla_z H_\theta(z(t)) \iff \begin{cases} \dot{q} = \nabla_p H_\theta(q, p) \\ \dot{p} = -\nabla_q H_\theta(q, p) \end{cases}
The trajectory map \Phi_t: \mathcal{M} \to \mathcal{M} induced by X_H defines an
exact 1-parameter group of symplectomorphisms satisfying:
\left( \frac{\partial \Phi_t(z)}{\partial z} \right)^T J \left( \frac{\partial \Phi_t(z)}{\partial z} \right) = J, \quad \det\left( \frac{\partial \Phi_t(z)}{\partial z} \right) = 1 \quad \forall t \in \mathbb{R}

1.3. Poisson Lie Algebra & Noether Conservation

For smooth functionals F, G \in C^\infty(\mathcal{M}), the bilinear,
antisymmetric Poisson bracket is defined by:
\{F, G\} = \omega(X_F, X_G) = (\nabla_z F)^T J (\nabla_z G) = \sum_{i=1}^d \left( \frac{\partial F}{\partial q^i} \frac{\partial G}{\partial p^i} - \frac{\partial F}{\partial p^i} \frac{\partial G}{\partial q^i} \right)
By Noether's Theorem, a functional Q_\phi \in C^\infty(\mathcal{M}) corresponds
to an invariant of motion along the system trajectory generated by H_\theta if
and only if its Lie derivative along X_H vanishes:
\mathcal{L}_{X_H} Q_\phi = \frac{d Q_\phi}{dt} = \{Q_\phi, H_\theta\} = (\nabla_z Q_\phi)^T J (\nabla_z H_\theta) \equiv 0
When multiple invariants \{Q_1, \dots, Q_k\} commute closure-wise, they define
the basis of a Lie algebra \mathfrak{g} with structure constants c_{ab}^c:
\{Q_a, Q_b\} = \sum_{c=1}^k c_{ab}^c Q_c

# Escopo científico e validação

## Contratos implementados

| Área | Implementação | Verificação |
|---|---|---|
| Geometria canônica | J como buffer, campos Hamiltonianos, Poisson autodiff, teste de simpléticidade | Colchetes canônicos d=1,2,3, potencial central, Jacobianos não lineares |
| Integração | Midpoint implícito diferenciável com falha explícita de convergência; Yoshida separável | Reversibilidade, mapas tangentes cumulativos, erro de estrutura |
| Álgebra de Lie | JVPs, mínimos quadrados de constantes, derivada de Lie da métrica | Translação/dilatação e campo rotacional de Killing |
| Modelos H/L | MLPs suaves, resíduos dinâmicos, Hessiana Euler–Lagrange | Aprendizado com redução de loss, aceleração analítica e gradientes de parâmetros |
| Memória | Sensibilidades de invariantes e projeção sem matriz P×P | Resíduo nulo sem damping e redução com damping, inclusive vínculos dependentes |
| Noether | Objetivo com comutador, variância e ortogonalidade | Gradientes finitos e redução de objetivo; não se afirma convergência única |
| Conservação | Máximo drift relativo e limite Hoeffding separado para falhas IID | Rejeição de drift/NaN; demonstração conservativa |
| Topologia | Seção de Poincaré interpolada, dimensão de correlação e métrica pullback | Órbita circular e fluxo linear |
| Síntese | AST segura sem eval, busca limitada, ajuste quadrático, fronteira de complexidade/erro, registro dinâmico | Lz exato, R² em dados separados, aridade e registro |
| Semântica | Adaptador de modelo opcional, projeção InfoNCE, vocabulário explícito xy | Backend injetado, backward contrastivo, gerador canônico |
| Streaming | Buffer limitado, diferenças finitas/EMA, runtime cancelável, replay e intervenções | Aprendizado altera pesos, fila, cancelamento, filtro |
| Visualização | Slice 3D, órbitas de geradores, WebSocket e canvas | Geometria gerada, roundtrip real, inspeção automatizada do navegador |

## Correções e limites da especificação

1. Simpléticidade não significa conservação exata da energia nem estabilidade por tempo infinito. Há erro de discretização, arredondamento e convergência; o midpoint ajusta sua tolerância mínima à precisão do tensor. Os testes usam float64. Verificações em um estado inicial de baixa energia não provam todos os regimes caóticos.
2. O pêndulo duplo canônico não tem Hamiltoniano separável `T(p)+V(q)`. Ele é validado com midpoint; executar Yoshida separável nesse modelo seria matematicamente incorreto. O teste Yoshida de 50.000 passos usa Hénon–Heiles. Os testes mantêm o mapa tangente cumulativo, sem confundi-lo com Jacobianos isolados.
3. O objetivo Noether tem vários mínimos e degenerações. O teste de aprendizado exige redução mensurável, não finge que a otimização tem uma solução única Lz. O teste de cristalização recebe o Lz analítico como alvo. A descoberta neural irrestrita solicitada permanece uma meta de pesquisa não demonstrada.
4. A penalização de variância não garante não trivialidade nem independência funcional. Um invariante varia entre órbitas, mas é constante numa órbita individual. O runtime conserva um buffer de uma sequência e pode corretamente não produzir nenhuma descoberta. Pontos intercalados de uma mesma trajetória não são amostras IID nem comprovam generalização física. A saída é um candidato empírico.
5. A projeção em parâmetros é Euclidiana; não há forma simplética canônica dada sobre os pesos. Com damping positivo ela não é uma projeção ortogonal exata. Mesmo sem damping a restrição é apenas local e de primeira ordem; médias de sensibilidades podem cancelar e a base fica desatualizada. Não se comprovou retenção de Runge–Lenz após aprender um sistema quártico. Os testes não substituem esse experimento por uma alegação equivalente.
6. A busca simbólica é finita e pode não alcançar o R² solicitado; o chamador deve verificar fidelidade. A fronteira é calculada sobre candidatos visitados e usa contagem de nós como proxy de descrição, não um mínimo global de Kolmogorov. Ajustes polinomiais precisam de domínios suficientemente informativos. Operações fora do domínio real são descartadas sem mudar a fórmula.
7. Uma seção genérica de Poincaré não possui automaticamente coordenadas intrínsecas: por padrão retornam-se interseções em 2d; `chart_fn` fornece o mapa para 2d−1. A estimativa de dimensão é finita e depende das escalas e da amostragem; não demonstra existência de atratores dissipativos em sistemas Hamiltonianos.
8. Projeção contrastiva entre espaços de dimensões diferentes não é um difeomorfismo. Não se implementa um solver Gromov–Wasserstein nem recuperação automática de literatura. Embeddings sem treinamento pareado não identificam conceitos físicos por si sós.
9. Projeção para dimensão 3 é exclusivamente visual. Não existe forma simplética não degenerada em dimensão ímpar.
10. O filtro `p≈m dq/dt` pressupõe massa constante, coordenadas calibradas e intervalos uniformes. Não é um filtro canônico universal, especialmente no pêndulo duplo. A primeira amostra não entra no treinamento, pois não possui estimativa de velocidade.
11. Não há benchmark RTX, validação CUDA, captura de câmera real, modelo fundacional remoto, WebRTC, provas físicas, autenticação multiusuário ou SLA de produção nesta entrega. O canvas redesenha até a taxa do navegador e o servidor limita envio a 60 Hz; isso não comprova 60 FPS ou 120 atualizações/s. Os parâmetros e recursos dependem de dimensões/modelos escolhidos, não são tratados como orçamento garantido.
12. A configuração padrão serve a CPU. As redes especificadas somam mais parâmetros do que os números indicados no orçamento do anexo; o código prioriza as assinaturas e dimensões solicitadas, sem alegar que respeita o total estimado de 200 mil.

A CI padrão executa a suíte rápida, lint, demonstração, empacotamento e comparação byte a byte do TXT; os testes longos podem ser executados separadamente.

A aplicação de referência e as integrações opcionais têm estados de validação diferentes. Nenhum teste com backend semântico injetado deve ser interpretado como teste de um modelo fundacional baixado.

import pytest
import torch

from cnge_engine.math_core.integrators import ImplicitMidpointIntegrator, Yoshida4thIntegrator
from cnge_engine.math_core.symplectic import SymplecticManifold, scalar_gradient


def henon_heiles(z):
    q, p = z.chunk(2, -1)
    return (
        (q.square().sum(-1) + p.square().sum(-1)) / 2
        + q[..., 0] ** 2 * q[..., 1]
        - q[..., 1] ** 3 / 3
    )


def double_pendulum(z):
    # Canonical equal-mass/equal-length double pendulum; velocities are NOT momenta.
    q, p = z.chunk(2, -1)
    cosine = torch.cos(q[..., 0] - q[..., 1])
    kinetic = (p[..., 0] ** 2 + 2 * p[..., 1] ** 2 - 2 * p[..., 0] * p[..., 1] * cosine) / (
        2 * (2 - cosine**2)
    )
    return kinetic - 2 * torch.cos(q[..., 0]) - torch.cos(q[..., 1])


@pytest.mark.parametrize("H", [henon_heiles, double_pendulum])
def test_midpoint_nonlinear_symplectic_jacobian(H):
    m = SymplecticManifold(2, dtype=torch.float64)
    z = torch.tensor([[0.1, 0.2, 0.05, -0.1]], dtype=torch.float64, requires_grad=True)
    field = lambda x: m.hamiltonian_vector_field(scalar_gradient(H(x), x))
    step = lambda x: ImplicitMidpointIntegrator(max_iters=40, tol=1e-14).step(x, field, 0.01)
    jac = torch.autograd.functional.jacobian(step, z).reshape(4, 4)
    assert m.check_symplectomorphism(jac, 1e-10)[0]
    torch.testing.assert_close(
        ImplicitMidpointIntegrator(40, 1e-14).step(step(z), field, -0.01), z, atol=1e-12, rtol=1e-12
    )


def test_nonconvergence_and_nonseparable_rejection():

        ImplicitMidpointIntegrator(2).step(torch.ones(1, 2), lambda z: 100 * z, 1.0)
    with pytest.raises(ValueError, match="separable"):
        Yoshida4thIntegrator().step(torch.ones(1, 2), lambda z: z, 0.01)


@pytest.mark.parametrize("steps", [200, pytest.param(50000, marks=pytest.mark.long)])
def test_yoshida_henon_heiles_cumulative_tangent(steps):
    # Propagate the full tangent map; checking only individual step Jacobians is insufficient.
    dtype = torch.float64
    m = SymplecticManifold(2, dtype=dtype)
    q = torch.tensor([[0.1, 0.0]], dtype=dtype)
    p = torch.tensor([[0.0, 0.2]], dtype=dtype)
    tangent = torch.eye(4, dtype=dtype)
    integrator = Yoshida4thIntegrator()

    def grad_v(q):
        return torch.stack(
            (q[..., 0] + 2 * q[..., 0] * q[..., 1], q[..., 1] + q[..., 0] ** 2 - q[..., 1] ** 2), -1
        )

    def mapping(z):
        return torch.cat(integrator.step_separable(*z.chunk(2, -1), grad_v, lambda p: p, 0.01), -1)

    z = torch.cat((q, p), -1)
    maximum = 0.0
    for _ in range(steps):
        local = torch.func.jacrev(mapping)(z).reshape(4, 4)
        tangent = local @ tangent
        z = mapping(z)
        error = float(torch.linalg.matrix_norm(tangent.T @ m.J @ tangent - m.J))
        maximum = max(maximum, error)
    assert maximum < 1e-6


@pytest.mark.parametrize("H", [henon_heiles, double_pendulum])
@pytest.mark.long
def test_midpoint_50000_cumulative_tangent(H):
    m = SymplecticManifold(2, dtype=torch.float64)
    z = torch.tensor([[0.1, 0.0, 0.0, 0.2]], dtype=torch.float64)
    tangent = torch.eye(4, dtype=z.dtype)
    solver = ImplicitMidpointIntegrator(40, 1e-14)
    field = torch.func.grad(lambda x: H(x).sum())

    def vector(x):
        return m.hamiltonian_vector_field(field(x))

    for _ in range(50000):
        next_z = solver.step(z, vector, 0.01).detach()
        middle = (z + next_z) / 2
        derivative = torch.func.jacrev(vector)(middle).reshape(4, 4)
        identity = torch.eye(4, dtype=z.dtype)
        local = torch.linalg.solve(identity - 0.005 * derivative, identity + 0.005 * derivative)
        tangent = local @ tangent
        assert torch.linalg.matrix_norm(tangent.T @ m.J @ tangent - m.J) < 1e-6
        z = next_z

"""Deterministically concatenate tracked project text files, excluding the export itself."""

import argparse
import hashlib
import subprocess
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]


def export(output):
    names = subprocess.check_output(["git", "ls-files", "-z"], cwd=ROOT).decode().split("\0")
    names = sorted(n for n in names if n and n != "CNGE_SOURCE.txt" and (ROOT / n).is_file())
    chunks = [
        "CNGE — complete source archive (UTF-8)\n",
        "Each FILE section contains the original text of one tracked project file.\n",
    ]
    for name in names:
        data = (ROOT / name).read_bytes()
        text = data.decode("utf-8")
        chunks.append(
            f"\n{'=' * 80}\nFILE: {name}\nSHA256: {hashlib.sha256(data).hexdigest()}\n{'=' * 80}\n{text}"
        )
        if not text.endswith("\n"):
            chunks.append("\n")
    output.write_text("".join(chunks), encoding="utf-8")
    return len(names)


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--output", type=Path, default=ROOT / "CNGE_SOURCE.txt")
    print(f"Exported {export(parser.parse_args().output)} files")

            await asyncio.sleep(0.01)

    finally:
        await runtime.stop()
        await canvas.close()
        await asyncio.to_thread(http.shutdown)
