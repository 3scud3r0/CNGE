# CNGE-v2 — Robust continuous geometric discovery

O fluxo recomendado agora usa **autoencoder diferencial + EKF**, **gauge escalar normalizado**, **dicionários funcionais + STLSQ** e **adaptadores LoRA com proteção de ativações ou roteamento por tarefa**. O pacote `cnge_v2/` contém todos os módulos da especificação v2, pipeline, checkpoints, demonstração e testes.

As fórmulas do pedido exigiram correções: `uᵀJu=0` não define uma norma, imagens de posição isoladas não identificam momento e subespaços finitos podem saturar. [Contratos, demonstrações e limites](docs/V2_VALIDATION.md) explicam exatamente o que o código garante e o que foi medido. O estado é pesquisa/desenvolvimento validado em CPU, sem alegar garantias universais de produção ou descoberta científica.

## Instalar

Python 3.11+ (validação local: Python 3.12). Use o checkout existente: cada tarefa cloud já é isolada, sem necessidade de worktree.

```bash
cd /workspace/CNGE
python -m venv .venv
.venv/bin/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m pip check
```

O PyTorch CPU está explícito para evitar baixar distribuições CUDA sem necessidade. Para GPU, instale o PyTorch adequado ao driver conforme a documentação oficial e configure `device="cuda"`. Nenhum serviço externo ou segredo é necessário para o v2.

## Executar e validar

```bash
OPENBLAS_NUM_THREADS=1 .venv/bin/python -m cnge_v2.demo --output artifacts/v2-demo.json
OPENBLAS_NUM_THREADS=1 .venv/bin/pytest -q
.venv/bin/ruff check cnge_engine cnge_v2 tests tools
.venv/bin/ruff format --check cnge_engine cnge_v2 tests tools
.venv/bin/python -m build
```

Após instalação, `cnge-v2-demo` é equivalente ao módulo. A demonstração calibra coordenadas em telemetria ruidosa, executa ingestão → EKF → atualização LoRA → mineração e, separadamente, destila Runge–Lenz em cinco termos. Não apresenta o alvo analítico como uma descoberta neural autônoma.

A suíte normal inclui testes do v1 e v2. Três testes históricos de 50.000 passos exigem `pytest --long -m long -q`; a execução anterior levou cerca de 14 minutos. O v2 compartilha o mesmo midpoint validado, sem fallback Euler/RK4. [Resultados atuais](docs/V2_RESULTS.md) distinguem verificações atuais e históricas.

## Usar o pipeline

```python
import asyncio
import torch
from cnge_v2 import V2EngineConfig
from cnge_v2.execution.streaming_pipeline import StreamingEpistemicPipeline

async def run(calibration_pairs, sensor):
    # calibration_pairs: [B, 2, obs_dim], mesmo sensor e passo temporal do stream.
    engine = StreamingEpistemicPipeline(V2EngineConfig(
        obs_dim=calibration_pairs.shape[-1], latent_spatial_dim=2,
        device="cpu", protection_mode="task",
    ))
    engine.calibrate(calibration_pairs, steps=100)
    async for observation in sensor:
        telemetry = await engine.ingest_sensor_tick(observation)
        print(telemetry)
    engine.save_checkpoint("artifacts/model.pt")
    restored = StreamingEpistemicPipeline.load_checkpoint("artifacts/model.pt", device="cpu")
    return restored
```

Calibre com pares de observações igualmente espaçadas, normalizadas e representativas de várias trajetórias/energias. `Q_cov` e `R_cov` precisam refletir as unidades e o ruído do sensor. O encoder não é adaptado silenciosamente depois da calibração: uma mudança de carta invalidaria as garantias dos snapshots anteriores.

Para imagens de posição ou sensores sem estado observável em um frame, forme históricos com `ObservationHistory(frame_dim=128, length=4)` e configure `obs_dim=512`; `update(frame)` retorna `None` até preencher a janela, depois retorna o vetor concatenado. Prepare os pares de calibração com as mesmas janelas. Não se supõe que qualquer histórico arbitrário garanta observabilidade.

`LiveOrchestrator(engine, capacity=64, callback=...)` coordena um produtor e um worker com fila limitada, backpressure, cancelamento estruturado e propagação de erros. Aguarde `orchestrator.run(async_source)`. Não compartilhe o modelo com atualizações concorrentes fora desse worker.

### Aprendizado contínuo

- `protection_mode="activation"` é o padrão: protege a união dos subespaços capturados. Uma camada saturada gera `ActivationCapacityError`; expansão de características ou outra política exige uma decisão explícita.
- `protection_mode="task"` preserva snapshots nomeados e permite novos adaptadores completos. Após treinar um regime, use `engine.consolidate_task("regime_1")`; para inferência antiga, use `with engine.adapters.task("regime_1"):` ao avaliar energia/campo. Essa política requer contexto de tarefa e não promete proteção incondicional do campo ativo.
- `trigger_symbolic_distillation()` só consolida quando os gates de variância, comutador, R² separado e residual da fórmula passam. Retorna `None` quando não há evidência. Um sistema genérico com um grau de liberdade pode não ter outro invariante independente de H.

Os checkpoints preservam modelos, adaptadores e estados de otimização; filtros, filas e conexões reiniciam. Não recalibre a carta após congelar tarefas. A restauração de pesos não inicia serviços.

### Síntese analítica

`FunctionalDictionary` suporta monômios de grau limitado, trigonometria, filtros dimensionais/de escala e orçamento máximo de termos. `include_kepler=True` adiciona `q_i/r`, indispensável para Runge–Lenz. `ConstrainedSTLSQ.fit` aceita `constraints=C` para `C ξ=0`; `fit_gradient` ajusta gradientes de funções escalares, sem criar um campo não integrável. A complexidade é polinomial no tamanho explícito da biblioteca, que deve permanecer limitado.

O código `cnge_engine/` permanece disponível para comparação e compatibilidade. from dataclasses import dataclass, field

import numpy as np


@dataclass(frozen=True)
class ASTNode:
    op: str
    children: tuple = ()
    value: float | int | None = None

    def __post_init__(self):
        object.__setattr__(self, "children", tuple(self.children))
        arity = {
            "const": 0,
            "var": 0,
            "+": 2,
            "-": 2,
            "*": 2,
            "/": 2,
            "sin": 1,
            "cos": 1,
            "exp": 1,
            "ln": 1,
            "square": 1,
            "sqrt": 1,
        }
        if self.op not in arity or len(self.children) != arity[self.op]:
            raise ValueError("unknown operator or invalid arity")
        if self.op == "const" and (self.value is None or not np.isfinite(self.value)):
            raise ValueError("constant must be finite")
        if self.op == "var" and (not isinstance(self.value, int) or self.value < 0):
            raise ValueError("variable requires a nonnegative integer index")

    def evaluate(self, z):
        z = np.asarray(z)
        if self.op == "const":
            return np.full(z.shape[:-1], self.value, dtype=float)
        if self.op == "var":
            return z[..., self.value]
        args = [c.evaluate(z) for c in self.children]
        operations = {
            "+": np.add,
            "-": np.subtract,
            "*": np.multiply,
            "/": np.divide,
            "sin": np.sin,
            "cos": np.cos,
            "exp": np.exp,
            "ln": np.log,
            "square": np.square,
            "sqrt": np.sqrt,
        }
        # Invalid domains remain invalid: no protected division/log that changes the equation.
        with np.errstate(all="ignore"):
            return operations[self.op](*args)

    def to_latex(self):
        if self.op == "const":
            return f"{self.value:g}"
        if self.op == "var":
            return f"z_{{{self.value}}}"
        c = [child.to_latex() for child in self.children]
        if self.op in ("+", "-", "*"):
            symbol = r"\cdot" if self.op == "*" else self.op
            return f"({c[0]} {symbol} {c[1]})"
        if self.op == "/":
            return rf"\frac{{{c[0]}}}{{{c[1]}}}"
        if self.op == "square":
            return f"({c[0]})^2"
        if self.op == "sqrt":
            return rf"\sqrt{{{c[0]}}}"
        return rf"\{self.op}({c[0]})"

    def complexity(self):
        return 1 + sum(c.complexity() for c in self.children)

    def depth(self):
        return 1 + max((c.depth() for c in self.children), default=0)


@dataclass
class ASTGrammar:
    variable_count: int
    constants: tuple = (0.0, 1.0, -1.0, 0.5)
    binary_ops: tuple = ("+", "-", "*", "/")
    unary_ops: tuple = ("sin", "cos", "exp", "ln", "square", "sqrt")
    registered: dict = field(default_factory=dict)

    def __post_init__(self):
        if self.variable_count < 1:
            raise ValueError("variable_count must be positive")

    def terminals(self):
        return (
            [ASTNode("var", value=i) for i in range(self.variable_count)]
            + [ASTNode("const", value=c) for c in self.constants]
            + list(self.registered.values())
        )

from .ast_grammar import ASTNode


class DynamicOperatorRegistry:
    def __init__(self, base_grammar):
        self.grammar = base_grammar

    def register_crystallized_invariant(self, symbolic_node: ASTNode, latex_name: str):
        if not latex_name.strip():
            raise ValueError("operator name must be nonempty")

        def validate(node):
            if node.op == "var" and node.value >= self.grammar.variable_count:
                raise ValueError("operator references an out-of-domain variable")
            for child in node.children:
                validate(child)

        validate(symbolic_node)
        if (
            latex_name in self.grammar.registered
            and self.grammar.registered[latex_name] != symbolic_node
        ):
            raise ValueError("operator name already registered")
        # Preserve the expanded node's complexity; no cost-free macro compression.
        self.grammar.registered[latex_name] = symbolic_node

    def get_active_grammar(self):
        return self.grammar

import itertools
from dataclasses import dataclass

import numpy as np

from .ast_grammar import ASTNode


@dataclass(frozen=True)
class Candidate:
    node: ASTNode
    mse: float
    r2: float


class ParetoSymbolicCompiler:
    """Bounded search plus quadratic least squares. No global-optimum guarantee."""

    def __init__(self, grammar, max_depth=6, beam_width=64, mdl_weight=0.05):
        if max_depth < 1 or beam_width < 1 or mdl_weight < 0:
            raise ValueError("invalid search budget")
        self.grammar, self.max_depth, self.beam_width = grammar, max_depth, beam_width
        self.mdl_weight = mdl_weight
        self.frontier = []

    def compile(self, target_eval_fn, z_domain, r2_target=0.9999):
        z = np.asarray(z_domain, dtype=float)
        if (
            z.ndim != 2
            or z.shape[1] != self.grammar.variable_count
            or len(z) < 2
            or not np.isfinite(z).all()
        ):
            raise ValueError("invalid symbolic domain")
        y = np.asarray(target_eval_fn(z), dtype=float).reshape(-1)
        if len(y) != len(z) or not np.isfinite(y).all() or not 0 <= r2_target <= 1:
            raise ValueError("invalid target evaluations or R2 target")
        variance = np.mean((y - y.mean()) ** 2)
        seen, candidates = set(), []

        def add(node):
            if node.depth() > self.max_depth or node in seen:
                return
            seen.add(node)
            values = node.evaluate(z)
            if not np.isfinite(values).all():
                return
            with np.errstate(over="ignore"):
                mse = float(np.mean((values - y) ** 2))
            if not np.isfinite(mse):
                return
            r2 = 1 - mse / variance if variance > 1e-24 else float(mse < 1e-24)
            candidates.append(Candidate(node, mse, r2))

        terminals = self.grammar.terminals()
        for node in terminals:
            add(node)
        # Fit sparse quadratic signatures; all retained coefficients are explicit AST constants.
        variables = [ASTNode("var", value=i) for i in range(z.shape[1])]
        features = [ASTNode("const", value=1.0), *variables]
        features += [
            ASTNode("*", (a, b)) for a, b in itertools.combinations_with_replacement(variables, 2)
        ]
        coefficients = np.linalg.lstsq(
            np.stack([f.evaluate(z) for f in features], 1), y, rcond=None
        )[0]
        terms = []
        for coefficient, feature in zip(coefficients, features):
            if abs(coefficient) < 1e-9:
                continue
            rounded = round(float(coefficient), 10)
            term = (
                feature
                if abs(rounded - 1) < 1e-9
                else ASTNode("*", (ASTNode("const", value=rounded), feature))
            )
            terms.append(term)
        if terms:
            node = terms[0]
            for term in terms[1:]:
                # Emit subtraction for negative unit factors, preserving angular-momentum structure.
                if (
                    term.op == "*"
                    and term.children[0].op == "const"
                    and term.children[0].value == -1
                ):
                    node = ASTNode("-", (node, term.children[1]))
                else:
                    node = ASTNode("+", (node, term))
            add(node)
        for _ in range(self.max_depth - 1):
            accurate = [c for c in candidates if c.r2 >= r2_target]
            if accurate:
                break
            beam = sorted(candidates, key=lambda c: c.mse + self.mdl_weight * c.node.complexity())[
                : self.beam_width
            ]
            for c in beam:
                for op in self.grammar.unary_ops:
                    add(ASTNode(op, (c.node,)))
                for other in terminals:
                    for op in self.grammar.binary_ops:
                        add(ASTNode(op, (c.node, other)))
                        if op in ("-", "/"):
                            add(ASTNode(op, (other, c.node)))
        ordered = sorted(candidates, key=lambda c: (c.node.complexity(), c.mse))
        self.frontier = []
        best = float("inf")
        for c in ordered:
            if c.mse < best:
                self.frontier.append(c)
                best = c.mse
        accurate = [c for c in self.frontier if c.r2 >= r2_target]
        if accurate:
            return min(accurate, key=lambda c: (c.node.complexity(), c.mse)).node
        return min(self.frontier, key=lambda c: c.mse + self.mdl_weight * c.node.complexity()).node

import torch


class PhaseTopologyAnalyzer:
    def __init__(self, manifold):
        self.manifold = manifold

    def compute_poincare_map(self, trajectory, surface_fn, chart_fn=None):
        """Positive transverse crossings, linearly interpolated in ambient coordinates.

        A user-supplied surface chart is required to return intrinsic 2d-1 coordinates.
        A general surface has no canonical coordinate that can safely be dropped.
        """
        if trajectory.ndim != 2 or len(trajectory) < 2:
            raise ValueError("expected [T,2d], T>=2")
        s = surface_fn(trajectory).reshape(-1)
        if len(s) != len(trajectory):
            raise ValueError("surface must return one value per point")
        indices = torch.where((s[:-1] < 0) & (s[1:] >= 0))[0]
        fraction = -s[indices] / (s[indices + 1] - s[indices])
        points = trajectory[indices] + fraction[:, None] * (
            trajectory[indices + 1] - trajectory[indices]
        )
        return chart_fn(points) if chart_fn else points

    def detect_attractor_dimensionality(self, trajectory):
        """Finite-sample correlation dimension, with bounded O(2048^2) memory."""
        if trajectory.ndim != 2 or len(trajectory) < 20 or not torch.isfinite(trajectory).all():
            raise ValueError("need at least 20 finite trajectory points")
        stride = max(1, (len(trajectory) + 2047) // 2048)
        distances = torch.pdist(trajectory[::stride]).double()
        distances = distances[distances > 0]
        if len(distances) < 10:
            raise ValueError("degenerate trajectory")
        lo, hi = torch.quantile(
            distances, torch.tensor([0.05, 0.5], device=distances.device, dtype=distances.dtype)
        )
        if hi <= lo:
            raise ValueError("no usable scale interval")
        radii = torch.exp(torch.linspace(lo.log(), hi.log(), 16, device=lo.device))
        counts = (distances[:, None] < radii).double().mean(0)
        valid = (counts > 0) & (counts < 1)
        if valid.sum() < 3:
            raise ValueError("insufficient correlation scales")
        x, y = radii[valid].log(), counts[valid].log()
        return float(((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean()) ** 2).sum())

    @staticmethod
    def pullback_metric(flow_fn, z):
        jacobians = torch.stack([torch.func.jacrev(flow_fn)(point) for point in z])
        return jacobians.transpose(-1, -2) @ jacobians

import torch
from torch import nn

from ..math_core.symplectic import scalar_gradient


class SmoothSoftplus(nn.Module):
    """Stable softplus without the piecewise linear threshold of nn.Softplus."""

    def __init__(self, beta=5.0):
        super().__init__()
        if beta <= 0:
            raise ValueError("beta must be positive")
        self.beta = beta

    def forward(self, x):
        return torch.logaddexp(torch.zeros_like(x), self.beta * x) / self.beta


def smooth_mlp(input_dim, hidden_dims, beta=5.0):
    layers = []
    previous = input_dim
    for width in hidden_dims:
        layers.extend((nn.Linear(previous, width), SmoothSoftplus(beta)))
        previous = width
    return nn.Sequential(*layers, nn.Linear(previous, 1))


class HamiltonianNN(nn.Module):
    def __init__(self, manifold, hidden_dims=(128, 128, 128), beta=5.0):
        super().__init__()
        self.manifold = manifold
        self.network = smooth_mlp(2 * manifold.spatial_dim, hidden_dims, beta).to(manifold.J)

    def forward(self, z):
        return self.network(z)

    def predict_vector_field(self, z):
        with torch.enable_grad():
            if not z.requires_grad:
                z = z.detach().requires_grad_(True)
            return self.manifold.hamiltonian_vector_field(scalar_gradient(self(z), z))

    def trajectory_loss(self, z_observed, dt):
        if dt <= 0 or z_observed.ndim != 3 or z_observed.shape[1] != 2:
            raise ValueError("expected [B,2,2d] and positive dt")
        midpoint = z_observed.mean(1)
        observed = (z_observed[:, 1] - z_observed[:, 0]) / dt
        return ((self.predict_vector_field(midpoint) - observed) ** 2).sum(-1).mean()

class LagrangianNN(nn.Module):
    def __init__(self, spatial_dim, hidden_dims=(128, 128)):
        super().__init__()
        self.spatial_dim = spatial_dim
        self.network = smooth_mlp(2 * spatial_dim, hidden_dims)

    def forward(self, q, q_dot):
        return self.network(torch.cat((q, q_dot), -1))

    def compute_acceleration(self, q, q_dot):
        def scalar(qi, vi):
            return self(qi[None], vi[None]).sum()

        rows = []
        for qi, vi in zip(q, q_dot):
            dLq = torch.func.grad(scalar, argnums=0)(qi, vi)
            momentum = torch.func.grad(scalar, argnums=1)
            mass = torch.func.jacrev(momentum, argnums=1)(qi, vi)
            mixed = torch.func.jacrev(momentum, argnums=0)(qi, vi)
            # Singular/ill-conditioned learned mass matrices must not be silently inverted.
            if not torch.isfinite(mass).all() or torch.linalg.cond(mass).detach() > 1e10:
                raise RuntimeError("singular or ill-conditioned Lagrangian mass matrix")
            rows.append(torch.linalg.solve(mass, dLq - mixed @ vi))
        return torch.stack(rows)

import torch


class SymplecticSubspaceProtector:
    """Low-rank Euclidean parameter projection; preservation is local, not a theorem of retention."""

    def __init__(self, parameter_dim, damping=1e-4):
        if parameter_dim < 1 or damping < 0:
            raise ValueError("invalid projection dimensions or damping")
        self.parameter_dim, self.damping = parameter_dim, damping
        self.rows = []

    def register_invariant(self, Q_invariant_fn, H_model, validation_samples):
        z = validation_samples.detach().requires_grad_(True)
        residual = H_model.manifold.poisson_bracket(Q_invariant_fn(z), H_model(z), z).mean()
        params = [p for p in H_model.parameters() if p.requires_grad]
        if sum(p.numel() for p in params) != self.parameter_dim:
            raise ValueError("parameter dimension mismatch")
        grads = torch.autograd.grad(residual, params, allow_unused=True)
        self.rows.append(
            torch.cat(
                [
                    (torch.zeros_like(p) if g is None else g).reshape(-1)
                    for p, g in zip(params, grads)
                ]
            ).detach()
        )

    def project_gradient(self, raw_gradient):
        if raw_gradient.shape != (self.parameter_dim,):
            raise ValueError("expected a flat parameter gradient")
        if not self.rows:
            return raw_gradient.clone()
        A = torch.stack(self.rows).to(raw_gradient)
        if self.damping == 0:
            return raw_gradient - torch.linalg.pinv(A) @ (A @ raw_gradient)
        gram = A @ A.T + self.damping * torch.eye(len(A), device=A.device, dtype=A.dtype)
        return raw_gradient - A.T @ torch.linalg.solve(gram, A @ raw_gradient)

import math
from abc import ABC, abstractmethod

import torch


class SymplecticIntegrator(ABC):
    @abstractmethod
    def step(self, z_t, vector_field_fn, dt):
        raise NotImplementedError


def _validate_dt(dt):
    if not math.isfinite(dt):
        raise ValueError("dt must be finite")


class ImplicitMidpointIntegrator(SymplecticIntegrator):
    """Differentiable fixed-point solve; raises instead of accepting nonconvergence."""

    def __init__(self, max_iters=20, tol=1e-12):
        if max_iters < 1 or tol <= 0:
            raise ValueError("invalid solver controls")
        self.max_iters, self.tol = max_iters, tol

    def step(self, z_t, vector_field_fn, dt):
        _validate_dt(dt)
        estimate = z_t
        for _ in range(self.max_iters):
            updated = z_t + dt * vector_field_fn((z_t + estimate) / 2)
            residual = (updated - estimate).detach().abs().max()
            if not torch.isfinite(updated).all():
                raise RuntimeError("nonfinite midpoint iterate")
            # A precision floor is necessary for float32; float64 retains the requested tolerance.
            threshold = max(
                self.tol,
                4 * torch.finfo(z_t.dtype).eps * max(1.0, float(updated.detach().abs().max())),
            )
            estimate = updated
            if residual <= threshold:
                return estimate
        raise RuntimeError("implicit midpoint did not converge; reduce dt or increase max_iters")


class Yoshida4thIntegrator(SymplecticIntegrator):
    """Fourth order composition for explicitly separable H=T(p)+V(q)."""

    def step(self, z_t, vector_field_fn, dt):
        raise ValueError("Yoshida requires explicit grad_V_fn and grad_T_fn; use step_separable")

    def step_separable(self, q_t, p_t, grad_V_fn, grad_T_fn, dt):
        _validate_dt(dt)
        w1 = 1 / (2 - 2 ** (1 / 3))
        w0 = -(2 ** (1 / 3)) * w1
        q, p = q_t, p_t
        for weight in (w1, w0, w1):
            p = p - dt * weight / 2 * grad_V_fn(q)
            q = q + dt * weight * grad_T_fn(p)
            p = p - dt * weight / 2 * grad_V_fn(q)
        return q, p

import torch


class LieAlgebraEngine:
    @staticmethod
    def lie_bracket_fields(X_fn, Y_fn, z):
        _, dy_x = torch.autograd.functional.jvp(Y_fn, z, X_fn(z), create_graph=True)
        _, dx_y = torch.autograd.functional.jvp(X_fn, z, Y_fn(z), create_graph=True)
        return dy_x - dx_y

    def structure_constants(self, basis_fields, z_samples):
        if not basis_fields:
            raise ValueError("empty basis")
        design = torch.stack([fn(z_samples).reshape(-1) for fn in basis_fields], -1)
        rows = []
        for x in basis_fields:
            rows.append(
                torch.stack(
                    [
                        torch.linalg.lstsq(
                            design, self.lie_bracket_fields(x, y, z_samples).reshape(-1, 1)
                        ).solution[:, 0]
                        for y in basis_fields
                    ]
                )
            )
        return torch.stack(rows)

    @staticmethod
    def killing_residual(X_fn, metric_fn, z):
        """Pointwise Lie derivative of a metric, shape [B,n,n]."""

        def point(x):
            X = X_fn(x[None])[0]
            g = metric_fn(x[None])[0]
            jac = torch.func.jacrev(lambda t: X_fn(t[None])[0])(x)
            dg = torch.func.jacrev(lambda t: metric_fn(t[None])[0])(x)
            return torch.einsum("ijk,k->ij", dg, X) + jac.T @ g + g @ jac

        return torch.stack([point(x) for x in z])

import torch
from torch import nn


def scalar_gradient(value, z):
    """Gradient of independent scalar evaluations, including constant functions."""
    if not value.requires_grad:
        return z * 0
    grad = torch.autograd.grad(
        value.sum(), z, create_graph=True, retain_graph=True, allow_unused=True
    )[0]
    return z * 0 if grad is None else grad


class SymplecticManifold(nn.Module):
    def __init__(self, spatial_dim, device="cpu", dtype=torch.float32):
        super().__init__()
        if spatial_dim < 1:
            raise ValueError("spatial_dim must be positive")
        self.spatial_dim = spatial_dim
        eye = torch.eye(spatial_dim, device=device, dtype=dtype)
        zero = torch.zeros_like(eye)
        self.register_buffer(
            "J", torch.cat((torch.cat((zero, eye), 1), torch.cat((-eye, zero), 1)), 0)
        )

    def canonical_matrix(self):
        return self.J

    def hamiltonian_vector_field(self, grad_H):
        if grad_H.shape[-1] != self.J.shape[0]:
            raise ValueError("incorrect phase dimension")
        return grad_H @ self.J.T

    def poisson_bracket(self, f, g, z):
        if not z.requires_grad:
            raise ValueError("z must require gradients")
        return (scalar_gradient(f, z) * self.hamiltonian_vector_field(scalar_gradient(g, z))).sum(
            -1, keepdim=True
        )

    def check_symplectomorphism(self, jacobian_map, tol=1e-6):
        error = jacobian_map.transpose(-1, -2) @ self.J @ jacobian_map - self.J
        return bool(torch.linalg.matrix_norm(error).max() < tol), error

import math

import torch


class ConservationVerifier:
    """Empirical relative trajectory drift; confidence bounds require independent bounded samples."""

    def __init__(self, manifold, tolerance=1e-4, confidence=0.999):
        if tolerance <= 0 or not 0 < confidence < 1:
            raise ValueError("invalid verification settings")
        self.manifold, self.tolerance, self.confidence = manifold, tolerance, confidence

    def verify_trajectory_invariance(self, Q_fn, trajectories):
        if trajectories.ndim != 3 or trajectories.shape[1] < 2 or not trajectories.numel():
            raise ValueError("expected nonempty [B,T,2d], T>=2")
        values = Q_fn(trajectories.reshape(-1, trajectories.shape[-1])).reshape(
            *trajectories.shape[:2], -1
        )
        initial = values[:, :1]
        drift = ((values - initial).abs() / (initial.abs() + torch.finfo(values.dtype).eps)).max()
        metric = float(drift.detach())
        return math.isfinite(metric) and metric < self.tolerance, metric

    def bounded_failure_upper_bound(self, failures, sample_count):
        """Hoeffding upper bound on Bernoulli failure rate for IID trajectories, not timesteps."""
        if not 0 <= failures <= sample_count or sample_count < 1:
            raise ValueError("invalid sample counts")
        return min(
            1.0,
            failures / sample_count
            + math.sqrt(math.log(1 / (1 - self.confidence)) / (2 * sample_count)),
        )

    def inject_user_intervention(self, intervention_packet):
        kind = intervention_packet.get("type")
        if kind == "perturbation":
            delta = torch.as_tensor(
                intervention_packet["delta"], device=self.config.device, dtype=self.config.dtype
            )
            if delta.shape != (2 * self.config.spatial_dim,) or not torch.isfinite(delta).all():
                raise ValueError("delta must be a finite phase vector")
        elif kind == "constraint":
            BidirectionalTranslator(None, None, self.registry).prompt_to_geometric_constraint(
                intervention_packet["prompt"]
            )
        else:
            raise ValueError("unknown intervention type")
        self.interventions.put_nowait(dict(intervention_packet))

    def _apply_interventions(self):
        while not self.interventions.empty():
            packet = self.interventions.get_nowait()
            if packet["type"] == "perturbation":
                self.offset += torch.as_tensor(
                    packet["delta"], device=self.offset.device, dtype=self.offset.dtype
                )
                # A discontinuity must not be treated as a dynamical training pair.
                self.previous = None
                self.buffer.clear()
            else:
                self.rotation_constraint = True

    def _learn(self, pairs):
        self.h_optimizer.zero_grad(set_to_none=True)
        loss = self.hamiltonian.trajectory_loss(pairs, self.config.integrator_dt)
        if self.rotation_constraint:
            z = pairs[:, 0].detach().requires_grad_(True)
            d = self.config.spatial_dim
            L = z[:, :1] * z[:, d + 1 : d + 2] - z[:, 1:2] * z[:, d : d + 1]
            loss = loss + self.manifold.poisson_bracket(L, self.hamiltonian(z), z).square().mean()
        loss.backward()
        params = list(self.hamiltonian.parameters())
        flat = torch.cat(
            [(torch.zeros_like(p) if p.grad is None else p.grad).reshape(-1) for p in params]
        )
        projected = self.protector.project_gradient(flat)
        offset = 0
        for p in params:
            p.grad = projected[offset : offset + p.numel()].reshape_as(p).clone()
            offset += p.numel()
        self.h_optimizer.step()
        self.q_optimizer.zero_grad(set_to_none=True)
        mining_loss, metrics = self.miner.compute_loss(pairs[:, 0], self.hamiltonian)
        gradients = torch.autograd.grad(mining_loss, self.miner.parameters())
        for p, grad in zip(self.miner.parameters(), gradients):
            p.grad = grad
        self.q_optimizer.step()
        self.metrics = {
            "dynamics_loss": float(loss.detach()),
            "mining_loss": float(mining_loss.detach()),
            **metrics,
        }

    def _try_discovery(self):
        if len(self.buffer) < 32:
            return
        samples = torch.cat(list(self.buffer))
        training, heldout = samples[::2], samples[1::2]
        z = heldout.detach().requires_grad_(True)
        Q = self.miner(z)
        bracket = self.manifold.poisson_bracket(Q, self.hamiltonian(z), z)
        if (
            float(Q.detach().var()) < self.config.min_invariant_variance
            or float(bracket.detach().abs().max()) >= self.config.poisson_threshold
        ):
            return
        trajectory = samples.unsqueeze(0)
        valid, drift = self.verifier.verify_trajectory_invariance(self.miner, trajectory)
        if not valid:
            return

        def target(array):
            with torch.no_grad():
                tensor = torch.as_tensor(array, device=self.config.device, dtype=self.config.dtype)
                return self.miner(tensor).cpu().numpy().reshape(-1)

        node = self.compiler.compile(target, training.cpu().numpy())
        actual = target(heldout.cpu().numpy())
        predicted = node.evaluate(heldout.cpu().numpy())
        variance = np.var(actual)
        r2 = 1 - np.mean((predicted - actual) ** 2) / max(float(variance), 1e-24)
        if not np.isfinite(r2) or r2 < 0.9999 or node in self.registry.grammar.registered.values():
            return
        self.discovery_counter += 1
        name = f"Q_{self.discovery_counter}"
        self.registry.register_crystallized_invariant(node, name)
        self.protector.register_invariant(self.miner, self.hamiltonian, heldout)
        self.discovery_reports.append(
            {
                "name": name,
                "latex": node.to_latex(),
                "empirical_drift": drift,
                "heldout_r2": float(r2),
                "status": "empirical candidate; not a physical proof",
            }
        )
        # Bound metadata and protected subspace growth in a continuous process.
        self.discovery_reports = self.discovery_reports[-32:]
        self.protector.rows = self.protector.rows[-32:]
        if len(self.registry.grammar.registered) > 32:
            self.registry.grammar.registered.pop(next(iter(self.registry.grammar.registered)))

    async def process_observation(self, coordinates):
        self._apply_interventions()
        q = torch.as_tensor(coordinates, device=self.config.device, dtype=self.config.dtype)
        if q.ndim == 1:
            q = q[None]
        if q.shape != (1, self.config.spatial_dim):
            raise ValueError("runtime accepts one [d] or [1,d] sensor observation at a time")
        state = self.filter.update_and_extract_phase_point(q) + self.offset
        # First finite-difference velocity is undefined; skip it for training.
        if self.filter.previous is not None and self.updates == 0 and self.previous is None:
            self.updates += 1
            return state
        if self.previous is not None:
            pair = torch.stack((self.previous, state), 1)
            recent = list(self.buffer)[-31:] + [state.detach()]
            if len(recent) > 1:
                replay = torch.cat(recent)
                self._learn(torch.stack((replay[:-1], replay[1:]), 1))
            else:
                self._learn(pair)
        self.previous = state.detach()
        self.buffer.append(state.detach())
        self.updates += 1
        if self.config.integrator_type == "yoshida4":
            q1, p1 = Yoshida4thIntegrator().step_separable(
                *state.chunk(2, -1), *self.separable_gradients, self.config.integrator_dt
            )
            prediction = torch.cat((q1, p1), -1)
        else:
            prediction = self.integrator.step(
                state, self.hamiltonian.predict_vector_field, self.config.integrator_dt
            )
        if self.updates % self.config.discovery_interval == 0:
            self._try_discovery()
        if time.monotonic() >= self.next_replay:
            states = torch.cat(list(self.buffer))
            if len(states) >= 2:
                self._learn(torch.stack((states[:-1], states[1:]), 1))
            self.next_replay = time.monotonic() + self.config.memory_replay_interval_secs
        if self.canvas is not None and time.monotonic() - self._last_frame >= 1 / 60:
            vertices = SymplecticPhaseProjector(self.config.spatial_dim).project_to_3d(
                state[:, None]
            )
            await self.canvas.broadcast_phase_frame(
                {
                    "vertices": vertices.tolist(),
                    "metrics": self.metrics,
                    "discoveries": self.discovery_reports,
                }
            )
            self._last_frame = time.monotonic()
        return prediction.detach()

    async def _consume(self, source):
        async for coordinates in source:
            await self.process_observation(coordinates)
            await asyncio.sleep(0)

    def start_epistemic_runtime(self, source):
        if any(not task.done() for task in self.tasks):
            raise RuntimeError("runtime already active")
        self.tasks = [asyncio.create_task(self._consume(source), name="cnge-assimilation")]
        return self.tasks[0]

    async def stop(self):
        for task in self.tasks:
            if not task.done():
                task.cancel()
        results = await asyncio.gather(*self.tasks, return_exceptions=True)
        self.tasks = []
        for result in results:
            if isinstance(result, Exception):
                raise result

class ContinuousSensorStream:
    """Bounded telemetry buffer. Camera frames require an explicit frame-to-coordinate extractor."""

    def __init__(self, source_id, target_fps=60, capacity=4096):
        if target_fps <= 0 or capacity < 1:
            raise ValueError("invalid stream controls")
        self.source_id, self.target_fps = source_id, target_fps
        self.buffer = deque(maxlen=capacity)

    def push(self, coordinates):
        value = torch.as_tensor(coordinates).detach().clone()
        if value.ndim != 1 or not torch.isfinite(value).all():
            raise ValueError("coordinates must be a finite vector")
        if self.buffer and value.shape != self.buffer[-1].shape:
            raise ValueError("coordinate dimension changed")
        self.buffer.append(value)

    def get_state_buffer(self, window_size):
        if not 0 < window_size <= len(self.buffer):
            raise ValueError("insufficient samples or invalid window")
        return torch.stack(list(self.buffer)[-window_size:])

    async def capture(self, coordinate_extractor):
        try:
            import cv2
        except ImportError as exc:
            raise RuntimeError("install cnge-engine[camera] for camera capture") from exc
        capture = cv2.VideoCapture(self.source_id)
        try:
            if not capture.isOpened():
                raise RuntimeError("camera source unavailable")
            while True:
                ok, frame = await asyncio.to_thread(capture.read)
                if not ok:
                    break
                self.push(coordinate_extractor(frame))
                await asyncio.sleep(1 / self.target_fps)
        finally:
            capture.release()

import torch


class OnlineSymplecticStateFilter:
    """EMA finite differences with explicit constant mass; canonical only for that model."""

    def __init__(self, spatial_dim, dt, mass=1.0, smoothing=1.0):
        if spatial_dim < 1 or dt <= 0 or mass <= 0 or not 0 < smoothing <= 1:
            raise ValueError("invalid filter configuration")
        self.spatial_dim, self.dt, self.mass, self.smoothing = spatial_dim, dt, mass, smoothing
        self.previous = self.velocity = None

    def update_and_extract_phase_point(self, q_observed):
        if (
            q_observed.ndim != 2
            or q_observed.shape[-1] != self.spatial_dim
            or not q_observed.is_floating_point()
            or not torch.isfinite(q_observed).all()
        ):
            raise ValueError("expected finite floating [B,d] coordinates")
        q = q_observed.detach()
        if self.previous is not None and (
            self.previous.shape != q.shape
            or self.previous.device != q.device
            or self.previous.dtype != q.dtype
        ):
            raise ValueError("reset filter before changing batch/device/dtype")
        velocity = torch.zeros_like(q) if self.previous is None else (q - self.previous) / self.dt
        self.velocity = (
            velocity
            if self.velocity is None
            else self.smoothing * velocity + (1 - self.smoothing) * self.velocity
        )
        self.previous = q.clone()
        return torch.cat((q, self.mass * self.velocity), -1)

    def reset(self):
        self.previous = self.velocity = None

import asyncio
import inspect
import json

from websockets.asyncio.server import serve
from websockets.exceptions import ConnectionClosed


class InteractiveCanvasServer:
    """Loopback WebSocket transport, bounded messages and latest-frame delivery."""

    def __init__(self, port=8080, host="127.0.0.1"):
        self.port, self.host = port, host
        self.clients = {}
        self.callbacks = []
        self.server = None

    async def start(self):
        if self.server is not None:
            raise RuntimeError("server already started")
        self.server = await serve(
            self._handler,
            self.host,
            self.port,
            max_size=65536,
            max_queue=16,
            origins=[
                None,
                f"http://{self.host}:{self.port + 1}",
                f"http://localhost:{self.port + 1}",
            ],
        )
        self.port = self.server.sockets[0].getsockname()[1]
        return self

    async def _handler(self, socket):
        queue = asyncio.Queue(maxsize=1)
        self.clients[socket] = queue

        async def send():
            while True:
                await socket.send(await queue.get())

        sender = asyncio.create_task(send())
        try:
            async for message in socket:
                try:
                    packet = json.loads(message)
                    if not isinstance(packet, dict):
                        raise TypeError("interaction must be an object")
                    for callback in self.callbacks:
                        result = callback(packet)
                        if inspect.isawaitable(result):
                            await result
                except (ValueError, TypeError, KeyError, asyncio.QueueFull) as exc:
                    await socket.send(json.dumps({"error": str(exc)}))
        except ConnectionClosed:
            pass
        finally:
            self.clients.pop(socket, None)
            sender.cancel()
            await asyncio.gather(sender, return_exceptions=True)

    async def broadcast_phase_frame(self, frame_data):
        message = json.dumps(frame_data, allow_nan=False)
        for queue in tuple(self.clients.values()):
            if queue.full():
                queue.get_nowait()
            queue.put_nowait(message)

    def on_user_interaction(self, callback):
        self.callbacks.append(callback)

    async def close(self):
        if self.server:
            self.server.close()
            await self.server.wait_closed()
            self.server = None

class SymplecticPhaseProjector:
    """Display slice only: odd-dimensional 3D space cannot preserve a symplectic form."""

    def __init__(self, spatial_dim):
        self.spatial_dim = spatial_dim

    def project_to_3d(self, z_trajectories, projection_plane="canonical_canonical"):
        if (
            projection_plane != "canonical_canonical"
            or z_trajectories.shape[-1] != 2 * self.spatial_dim
        ):
            raise ValueError("unsupported projection or wrong phase dimension")
        d = self.spatial_dim
        if d == 1:
            points = torch.stack(
                (
                    z_trajectories[..., 0],
                    z_trajectories[..., 1],
                    torch.zeros_like(z_trajectories[..., 0]),
                ),
                -1,
            )
        else:
            points = z_trajectories[..., [0, 1, d]]
        return points.detach().cpu().numpy()

import math

import torch
from torch import nn

class ActivationCapacityError(RuntimeError):
    """The protected activation span exhausts a layer's finite input dimension."""


def orthonormal_union(existing, incoming):
    if (
        incoming.ndim != 2
        or incoming.shape[0] != existing.shape[0]
        or not torch.isfinite(incoming).all()
    ):
        raise ValueError("activation bases must be finite [input_dim, rank] matrices")
    joined = torch.cat((existing, incoming.to(existing)), 1)
    if joined.shape[1] == 0:
        return joined
    U, singular, _ = torch.linalg.svd(joined, full_matrices=False)
    tol = max(joined.shape) * torch.finfo(joined.dtype).eps * singular.max()
    return U[:, singular > tol].detach()


class FrozenAdapter(nn.Module):
    def __init__(self, A, B):
        super().__init__()
        self.register_buffer("A", A.detach().clone())
        self.register_buffer("B", B.detach().clone())

    def forward(self, x):
        return F.linear(F.linear(x, self.A), self.B)


class OrthogonalLoRALinear(nn.Module):
    def __init__(self, base, rank, protection_mode):
        super().__init__()
        self.base = base.requires_grad_(False)
        self.rank = min(rank, base.in_features, base.out_features)
        self.mode = protection_mode
        self.A = nn.Parameter(base.weight.new_empty(self.rank, base.in_features))
        self.B = nn.Parameter(base.weight.new_zeros(base.out_features, self.rank))
        self.register_buffer("U", base.weight.new_empty(base.in_features, 0))
        self.frozen = nn.ModuleList()
        self.selected_task = None
        self.reset_active()

    def reset_active(self):
        nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))
        nn.init.zeros_(self.B)

    def effective_A(self):
        if self.mode == "task":
            return self.A
        return self.A - (self.A @ self.U) @ self.U.T

    def forward(self, x):
        output = self.base(x)
        count = len(self.frozen) if self.selected_task is None else self.selected_task + 1
        for adapter in self.frozen[:count]:
            output = output + adapter(x)
        if self.selected_task is None:
            output = output + F.linear(F.linear(x, self.effective_A()), self.B)
        return output


class SymplecticLoRAEngine(nn.Module):
    """Low-rank energy adapters preserve Hamiltonian form through the scalar energy.

    Activation mode constrains new changes on a finite reference span. Task mode
    permits unrestricted new adapters and exact replay of named frozen snapshots.
    Neither mode proves context-free preservation of all physical invariants.
    """

    def __init__(self, base_model, rank=4, protection_mode="activation"):
        super().__init__()
        if rank < 1 or protection_mode not in ("activation", "task"):
            raise ValueError("invalid adapter configuration")
        self.base_model = base_model.requires_grad_(False).eval()
        self.protection_mode = protection_mode
        self.task_ids = []
        self.layers = {}
        for name, module in list(base_model.named_modules()):
            if isinstance(module, nn.Linear):
                parent_name, _, leaf = name.rpartition(".")
                parent = base_model.get_submodule(parent_name) if parent_name else base_model
                replacement = OrthogonalLoRALinear(module, rank, protection_mode)
                setattr(parent, leaf, replacement)
                self.layers[name] = replacement
        if not self.layers:
            raise ValueError("base_model must contain at least one Linear layer")

    def train(self, mode=True):
        super().train(mode)
        # Frozen running statistics and disabled dropout are part of snapshot reproducibility.
        self.base_model.eval()
        return self

    def forward(self, *args, **kwargs):
        self.base_model.eval()
        return self.base_model(*args, **kwargs)

    def active_parameters(self):
        return [p for layer in self.layers.values() for p in (layer.A, layer.B)]

    def assert_plastic_capacity(self):
        if self.protection_mode == "activation":
            saturated = [
                name
                for name, layer in self.layers.items()
                if layer.U.shape[1] == layer.base.in_features
            ]
            if saturated:
                raise ActivationCapacityError(
                    f"activation capacity exhausted in {saturated}; explicit task routing or feature expansion is required"
                )

    def active_adapter_state(self):
        return {
            f"{name}.{suffix}": getattr(layer, suffix).detach().clone()
            for name, layer in self.layers.items()
            for suffix in ("A", "B")
        }

    def capture_activation_subspaces(self, samples):
        activations = {name: [] for name in self.layers}
        handles = []
        for name, layer in self.layers.items():

            def hook(module, args, key=name):
                activations[key].append(args[0].detach().reshape(-1, module.base.in_features))

            handles.append(layer.register_forward_pre_hook(hook))
        try:
            with torch.no_grad():
                self(samples)
        finally:
            for handle in handles:
                handle.remove()
        result = {}
        for name, entries in activations.items():
            if not entries:
                raise ValueError(f"layer {name} was not evaluated")
            values = torch.cat(entries).T
            empty = values.new_empty(values.shape[0], 0)
            result[name] = orthonormal_union(empty, values)
        return result

    def register_frozen_invariant_adapter(self, task_id, adapter_weights, activation_subspace):
        if not isinstance(task_id, str) or not task_id or task_id in self.task_ids:
            raise ValueError("task_id must be unique and nonempty")
        if len(self.task_ids) >= 128:
            raise ActivationCapacityError("snapshot budget of 128 tasks exhausted")
        # Validate every layer before changing any model state.
        prepared = []
        for name, layer in self.layers.items():
            A = adapter_weights[f"{name}.A"].to(layer.A)
            B = adapter_weights[f"{name}.B"].to(layer.B)
            if (
                A.shape != layer.A.shape
                or B.shape != layer.B.shape
                or not torch.isfinite(A).all()
                or not torch.isfinite(B).all()
            ):
                raise ValueError("invalid adapter weights")
            incoming = (
                activation_subspace[name]
                if isinstance(activation_subspace, dict)
                else activation_subspace
            )
            union = orthonormal_union(layer.U, incoming)
            effective = A if layer.mode == "task" else A - (A @ layer.U) @ layer.U.T
            prepared.append((layer, effective, B, union))
        with torch.no_grad():
            for layer, A, B, union in prepared:
                layer.frozen.append(FrozenAdapter(A, B))
                layer.U = union
                layer.reset_active()
        self.task_ids.append(task_id)

    def get_orthogonalized_gradient(self, layer_name, raw_gradient):
        layer = self.layers[layer_name]
        if raw_gradient.shape != layer.base.weight.shape:
            raise ValueError("expected a dense [output_dim,input_dim] layer gradient")
        U = layer.U.to(raw_gradient)
        return raw_gradient - (raw_gradient @ U) @ U.T

    @contextmanager
    def task(self, task_id):
        if task_id is not None and task_id not in self.task_ids:
            raise KeyError(f"unknown task: {task_id}")
        previous = [layer.selected_task for layer in self.layers.values()]
        index = None if task_id is None else self.task_ids.index(task_id)
        try:
            for layer in self.layers.values():
                layer.selected_task = index
            yield self
        finally:
            for layer, value in zip(self.layers.values(), previous):
                layer.selected_task = value

    def get_extra_state(self):
        return {"task_ids": self.task_ids.copy(), "protection_mode": self.protection_mode}

    def set_extra_state(self, state):
        if state["protection_mode"] != self.protection_mode:
            raise ValueError("checkpoint protection mode differs")
        self.task_ids = list(state["task_ids"])

    def load_state_dict(self, state_dict, strict=True, assign=False):
        metadata = state_dict.get("_extra_state", {})
        tasks = metadata.get("task_ids", [])
        for name, layer in self.layers.items():
            prefix = f"base_model.{name}."
            layer.U = torch.empty_like(state_dict[prefix + "U"], device=layer.A.device)
            layer.frozen = nn.ModuleList(
                [
                    FrozenAdapter(
                        state_dict[prefix + f"frozen.{i}.A"].to(layer.A),
                        state_dict[prefix + f"frozen.{i}.B"].to(layer.B),
                    )
                    for i in range(len(tasks))
                ]
            )
        return super().load_state_dict(state_dict, strict=strict, assign=assign)

def sparse_kepler(seed=9):
    rng = np.random.default_rng(seed)
    library = FunctionalDictionary(
        [f"q_{i}" for i in range(3)] + [f"p_{i}" for i in range(3)], include_kepler=True
    )

    def sample():
        z = rng.normal(size=(512, 6))
        z[:, :3] += [2.0, 0.0, 0.0]
        q, p = z[:, :3], z[:, 3:]
        target = (np.cross(p, np.cross(q, p)) - q / np.linalg.norm(q, axis=1, keepdims=True))[:, 0]
        features, names = library.build_library(torch.from_numpy(z))
        return features.numpy(), target, names

    features, target, names = sample()
    start = time.perf_counter()
    formula, coefficients, r2 = ConstrainedSTLSQ().fit(features, target, names)
    seconds = time.perf_counter() - start
    test_features, test_target, _ = sample()
    test_r2 = 1 - np.mean((test_features @ coefficients - test_target) ** 2) / np.var(test_target)
    return {
        "formula": formula,
        "active_terms": int(np.count_nonzero(coefficients)),
        "training_r2": r2,
        "heldout_r2": float(test_r2),
        "fit_seconds": seconds,
        "scope": "Sparse distillation of analytical Runge-Lenz evaluations, not autonomous discovery.",
    }


async def run_demo(steps=20, calibration_steps=40):
    if steps < 2 or calibration_steps < 1:
        raise ValueError("steps >=2 and calibration_steps >=1 required")
    torch.manual_seed(12)
    torch.set_num_threads(1)
    config = V2EngineConfig(
        obs_dim=8,
        latent_spatial_dim=1,
        hidden_dim=16,
        dtype=torch.float64,
        device="cpu",
        protection_mode="task",
        observation_covariance=0.015**2,
    )
    pipeline = StreamingEpistemicPipeline(config)
    projection, _ = torch.linalg.qr(torch.randn(8, 2, dtype=config.dtype))
    phase = torch.linspace(0, 8, 64, dtype=config.dtype)

    def observe(angle):
        return torch.stack((angle.cos(), angle.sin()), -1) @ projection.T

    pairs = torch.stack((observe(phase), observe(phase + 0.01)), 1)
    pairs += 0.015 * torch.randn_like(pairs)
    history = pipeline.calibrate(pairs, steps=calibration_steps)
    telemetry = []

    async def source():
        for i in range(steps):
            yield observe(torch.tensor(i * 0.01, dtype=config.dtype)) + 0.015 * torch.randn(
                config.obs_dim, dtype=config.dtype
            )

    await LiveOrchestrator(pipeline, callback=telemetry.append).run(source())
    return {
        "calibration_initial_loss": history[0]["total_loss"],
        "calibration_final_loss": history[-1]["total_loss"],
        "ticks": len(telemetry),
        "last_tick": telemetry[-1],
        "kepler": sparse_kepler(),
        "scope": "Differential coordinate learning + EKF + online adapters. No claim of uniquely recovered physical canonical coordinates.",
    }


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--steps", type=int, default=20)
    parser.add_argument("--calibration-steps", type=int, default=40)
    parser.add_argument("--output", type=Path)
    args = parser.parse_args()
    report = asyncio.run(run_demo(args.steps, args.calibration_steps))
    text = json.dumps(report, indent=2)
    print(text)
    if args.output:
        args.output.parent.mkdir(parents=True, exist_ok=True)
        args.output.write_text(text + "\n")
    if report["kepler"]["heldout_r2"] < 0.999 or report["kepler"]["active_terms"] >= 6:
        raise SystemExit(1)


if __name__ == "__main__":
    main()

import asyncio

from .streaming_pipeline import StreamingEpistemicPipeline


class LiveOrchestrator:
    """Explicit bounded ingress, ordered single-worker updates and propagated errors."""

    def __init__(self, pipeline: StreamingEpistemicPipeline, capacity=64, callback=None):
        if capacity < 1:
            raise ValueError("capacity must be positive")
        self.pipeline, self.callback = pipeline, callback
        self.capacity = capacity
        self.queue = asyncio.Queue(maxsize=capacity)
        self._running = False

    async def run(self, source):
        if self._running:
            raise RuntimeError("orchestrator already running")
        self._running = True
        self.queue = asyncio.Queue(maxsize=self.capacity)
        sentinel = object()

        async def produce():
            async for observation in source:
                await self.queue.put(observation)
            await self.queue.put(sentinel)

        async def consume():
            while True:
                observation = await self.queue.get()
                try:
                    if observation is sentinel:
                        return
                    telemetry = await self.pipeline.ingest_sensor_tick(observation)
                    if self.callback:
                        result = self.callback(telemetry)
                        if hasattr(result, "__await__"):
                            await result
                    await asyncio.sleep(0)
                finally:
                    self.queue.task_done()

        try:
            async with asyncio.TaskGroup() as group:
                group.create_task(produce(), name="cnge-v2-ingestion")
                group.create_task(consume(), name="cnge-v2-learning")
        finally:
            self._running = False

from collections import deque

import torch


class ObservationHistory:
    """Bounded delay coordinates for sensors whose instantaneous frame is not observable."""

    def __init__(self, frame_dim, length=4):
        if frame_dim < 1 or length < 2:
            raise ValueError("positive frame dimension and at least two history frames required")
        self.frame_dim, self.length = frame_dim, length
        self.frames = deque(maxlen=length)

    def update(self, frame):
        value = torch.as_tensor(frame)
        if value.shape != (self.frame_dim,) or not torch.isfinite(value).all():
            raise ValueError("one finite frame vector is required")
        if self.frames and (
            value.dtype != self.frames[0].dtype or value.device != self.frames[0].device
        ):
            raise ValueError("reset history before changing dtype/device")
        self.frames.append(value.detach().clone())
        return torch.cat(tuple(self.frames)) if len(self.frames) == self.length else None

    def reset(self):
        self.frames.clear()

import asyncio
from collections import deque
from dataclasses import asdict
from pathlib import Path

import numpy as np
import torch

from ..config.engine_config import V2EngineConfig
from ..core_dynamics.hamiltonian_surrogate import HamiltonianSurrogate
from ..core_dynamics.symplectic_lora import SymplecticLoRAEngine
from ..manifold.variational_autoencoder import SymplecticAutoencoder
from ..solvers.implicit_midpoint import ImplicitMidpointSolver
from ..solvers.kalman_manifold_filter import SymplecticEKF
from ..symbolic_distiller.constrained_stlsq import ConstrainedSTLSQ
from ..symbolic_distiller.functional_dictionary import FunctionalDictionary
from ..symmetry_engine.gauge_fixed_noether import DegenerateGaugeError, GaugeFixedNoetherMiner


class StreamingEpistemicPipeline:
    """Single-worker, serialized calibration/EKF/adapter/mining/distillation lifecycle."""

    def __init__(self, config: V2EngineConfig):
        self.config = config
        self.autoencoder = SymplecticAutoencoder(
            config.obs_dim,
            config.latent_spatial_dim,
            config.hidden_dim,
            observation_noise_variance=config.observation_covariance,
        ).to(device=config.device, dtype=config.dtype)
        self.hamiltonian = HamiltonianSurrogate(config.latent_spatial_dim, config.hidden_dim).to(
            device=config.device, dtype=config.dtype
        )
        self.adapters = SymplecticLoRAEngine(
            self.hamiltonian, config.lora_rank, config.protection_mode
        )
        self.miner = GaugeFixedNoetherMiner(
            config.latent_spatial_dim,
            config.hidden_dim,
            config.noether_orth_weight,
            config.noether_norm_weight,
        ).to(device=config.device, dtype=config.dtype)
        self.solver = ImplicitMidpointSolver(config.integrator_tol, config.integrator_max_iter)
        self.autoencoder.solver = self.solver
        self.filter = SymplecticEKF(
            config.latent_spatial_dim,
            config.process_covariance,
            config.observation_covariance,
            solver=self.solver,
        )
        self.optimizer = torch.optim.Adam(
            self.adapters.active_parameters(), lr=config.learning_rate
        )
        self.miner_optimizer = torch.optim.Adam(self.miner.parameters(), lr=config.learning_rate)
        d = config.latent_spatial_dim
        self.dictionary = FunctionalDictionary(
            [f"q_{i}" for i in range(d)] + [f"p_{i}" for i in range(d)],
            config.dictionary_degree,
            max_features=config.dictionary_max_features,
        )
        self.distiller = ConstrainedSTLSQ(config.stlsq_threshold, max_iter=config.stlsq_max_iter)
        self.buffer = deque(maxlen=config.buffer_size)
        self.reference = None
        self.posterior = self.covariance = self.previous = None
        self.ready = False
        self.last_metrics = {}
        self.discoveries = []
        self._lock = asyncio.Lock()
        self._sequence = 0

    def calibrate(self, x_seq, steps=100):
        if self.adapters.task_ids:
            raise RuntimeError("cannot change the shared coordinate chart after freezing a task")
        samples = torch.as_tensor(x_seq, device=self.config.device, dtype=self.config.dtype)
        if (
            samples.ndim != 3
            or samples.shape[1:] != (2, self.config.obs_dim)
            or len(samples) < 8
            or not torch.isfinite(samples).all()
            or steps < 1
        ):
            raise ValueError(
                "calibration needs at least 8 finite observation pairs [B,2,D] and steps>=1"
            )
        self.autoencoder.requires_grad_(True)
        optimizer = torch.optim.Adam(
            [*self.autoencoder.parameters(), *self.adapters.active_parameters()],
            lr=self.config.learning_rate,
        )
        history = []
        try:
            for _ in range(steps):
                optimizer.zero_grad(set_to_none=True)
                losses = self.autoencoder.compute_loss(
                    samples, self.config.integrator_dt, self.hamiltonian.energy
                )
                if not all(torch.isfinite(value) for value in losses.values()):
                    raise RuntimeError("nonfinite calibration loss")
                losses["total_loss"].backward()
                torch.nn.utils.clip_grad_norm_(
                    [*self.autoencoder.parameters(), *self.adapters.active_parameters()],
                    10.0,
                    error_if_nonfinite=True,
                )
                optimizer.step()
                history.append({key: float(value.detach()) for key, value in losses.items()})
        finally:
            self.autoencoder.requires_grad_(False)
        with torch.no_grad():
            self.reference = self.autoencoder.encoder(samples[:, 0]).detach()
        self.miner.set_reference(self.reference, self.hamiltonian)
        self.optimizer = torch.optim.Adam(
            self.adapters.active_parameters(), lr=self.config.learning_rate
        )
        self.reset_stream()
        self.ready = True
        return history

    def reset_stream(self):
        self.posterior = self.covariance = self.previous = None
        self.buffer.clear()

    def _learn(self):
        self.adapters.assert_plastic_capacity()
        if len(self.buffer) < 2:
            return {}
        recent = list(self.buffer)[-32:]
        z0 = torch.cat([entry[0] for entry in recent[:-1]])
        z1 = torch.cat([entry[0] for entry in recent[1:]])
        self.optimizer.zero_grad(set_to_none=True)
        predicted = self.solver.integrate_step(
            z0, self.hamiltonian.vector_field, self.config.integrator_dt
        )
        # Integrated latent and decoded-observation residuals; no q finite-difference momentum.
        observed = torch.cat([entry[1] for entry in recent[1:]])
        dynamics = (predicted - z1).square().mean() + (
            self.autoencoder.decoder(predicted) - observed
        ).square().mean()
        if not torch.isfinite(dynamics):
            raise RuntimeError("nonfinite dynamics loss")
        dynamics.backward()
        torch.nn.utils.clip_grad_norm_(
            self.adapters.active_parameters(), 10.0, error_if_nonfinite=True
        )
        self.optimizer.step()
        self.miner_optimizer.zero_grad(set_to_none=True)
        flags = [(p, p.requires_grad) for p in self.adapters.active_parameters()]
        try:
            for p, _ in flags:
                p.requires_grad_(False)
            loss, metrics = self.miner.compute_orthogonalized_loss(self.reference, self.hamiltonian)
            if not torch.isfinite(loss):
                raise RuntimeError("nonfinite Noether loss")
            gradients = torch.autograd.grad(loss, tuple(self.miner.parameters()))
            for p, gradient in zip(self.miner.parameters(), gradients):
                p.grad = gradient
            torch.nn.utils.clip_grad_norm_(self.miner.parameters(), 10.0, error_if_nonfinite=True)
            self.miner_optimizer.step()
            del gradients, loss
        except DegenerateGaugeError as error:
            metrics = {"gauge_rejection": str(error)}
        finally:
            for p, flag in flags:
                p.requires_grad_(flag)
        return {"dynamics_loss": float(dynamics.detach()), **metrics}

    async def ingest_sensor_tick(self, x_raw):
        async with self._lock:
            if not self.ready:
                raise RuntimeError("calibrate(x_seq) is required before ingesting observations")
            x = torch.as_tensor(x_raw, device=self.config.device, dtype=self.config.dtype)
            if x.ndim == 1:
                x = x[None]
            if x.shape != (1, self.config.obs_dim) or not torch.isfinite(x).all():
                raise ValueError("one finite raw observation [obs_dim] is required")
            with torch.no_grad():
                encoded = self.autoencoder.encoder(x)
            if self.posterior is None:
                prior = encoded
                covariance = torch.eye(
                    encoded.shape[-1], device=encoded.device, dtype=encoded.dtype
                )[None]
            else:
                prior, covariance = self.filter.predict(
                    self.posterior,
                    self.covariance,
                    self.hamiltonian.vector_field,
                    self.config.integrator_dt,
                )
            posterior, covariance = self.filter.update(
                prior, covariance, x, self.autoencoder.decoder
            )
            self.posterior, self.covariance = posterior, covariance
            self.buffer.append((posterior.detach(), x.detach()))
            self.last_metrics = self._learn()
            with torch.no_grad():
                energy = float(self.hamiltonian.energy(posterior).item())
            self._sequence += 1
            return {
                "sequence": self._sequence,
                "phase_coordinates": posterior[0].cpu().tolist(),
                "energy": energy,
                "metrics": self.last_metrics,
                "covariance_trace": float(torch.diagonal(covariance, dim1=-2, dim2=-1).sum()),
            }

    def consolidate_task(self, task_id):
        if not self.ready:
            raise RuntimeError("pipeline is not calibrated")
        subspaces = self.adapters.capture_activation_subspaces(self.reference)
        self.adapters.register_frozen_invariant_adapter(
            task_id, self.adapters.active_adapter_state(), subspaces
        )
        # Reset Adam moments when starting a new adapter; momentum must not leak across tasks.
        self.optimizer = torch.optim.Adam(
            self.adapters.active_parameters(), lr=self.config.learning_rate
        )
        self.reset_stream()

    def trigger_symbolic_distillation(self):
        if not self.ready or len(self.reference) < 32:
            return None
        training, heldout = self.reference[::2], self.reference[1::2]
        try:
            z = heldout.detach().requires_grad_(True)
            values = self.miner(z)
            bracket = self.hamiltonian.structure.poisson_bracket(values, self.hamiltonian(z), z)
            if (
                float(values.detach().var(unbiased=False)) <= self.config.min_discovery_variance
                or float(bracket.detach().square().mean()) >= self.config.max_commutator
            ):
                return None
            with torch.enable_grad():
                target = self.miner(training).detach().cpu().numpy()
            features, names = self.dictionary.build_library(training)
            constraints = (
                self.dictionary.conservation_constraints(training, self.hamiltonian.vector_field)
                .detach()
                .cpu()
                .numpy()
            )
            formula, coefficients, train_r2 = self.distiller.fit(
                features.detach().cpu().numpy(), target, names, constraints=constraints
            )
            heldout_features, _ = self.dictionary.build_library(heldout)
            predictions = heldout_features.detach().cpu().numpy() @ coefficients
            actual = values.detach().cpu().numpy().reshape(-1)
            r2 = 1 - np.mean((predictions - actual) ** 2) / max(float(np.var(actual)), 1e-24)
            if not np.isfinite(r2) or r2 < self.config.min_discovery_r2:
                return None
            # Check the synthesized scalar's own Poisson residual, not only the neural target.
            gradients, _ = self.dictionary.gradient_library(heldout)
            compiled_gradient = torch.einsum(
                "bmn,m->bn",
                gradients,
                torch.as_tensor(coefficients, device=z.device, dtype=z.dtype),
            )
            residual = (compiled_gradient * self.hamiltonian.vector_field(heldout)).sum(-1)
            if float(residual.detach().square().mean()) >= self.config.max_commutator:
                return None
        except DegenerateGaugeError:
            return None
        task_id = f"discovery_{len(self.adapters.task_ids) + 1}"
        report = {
            "task_id": task_id,
            "latex": formula,
            "r2": float(r2),
            "training_r2": train_r2,
            "coefficients": coefficients.tolist(),
            "features": names,
            "status": "empirically validated candidate on a finite latent reference set",
        }
        self.consolidate_task(task_id)
        self.discoveries.append(report)
        return report

    def save_checkpoint(self, path):
        if not self.ready:
            raise RuntimeError("cannot save an uncalibrated pipeline")
        config = asdict(self.config)
        config["dtype"] = str(self.config.dtype).split(".")[-1]
        payload = {
            "version": 2,
            "config": config,
            "autoencoder": self.autoencoder.state_dict(),
            "adapters": self.adapters.state_dict(),
            "miner_network": self.miner.network.state_dict(),
            "reference": self.reference,
            "optimizer": self.optimizer.state_dict(),
            "miner_optimizer": self.miner_optimizer.state_dict(),
            "discoveries": self.discoveries,
        }
        target = Path(path)
        target.parent.mkdir(parents=True, exist_ok=True)
        temporary = target.with_suffix(target.suffix + ".tmp")
        torch.save(payload, temporary)
        temporary.replace(target)

    @classmethod
    def load_checkpoint(cls, path, *, device="cpu"):
        payload = torch.load(path, map_location=device, weights_only=True)
        if payload["version"] != 2:
            raise ValueError("unsupported checkpoint")

import torch

from cnge_engine.math_core.symplectic import SymplecticManifold, scalar_gradient


class SymplecticStructure(SymplecticManifold):
    """A skew pairing, not an inner product: u^T J u is always zero."""

    def symplectic_gradient(self, grad_H):
        return self.hamiltonian_vector_field(grad_H)

    def pairing(self, u, v):
        return (u * (v @ self.J.T)).sum(-1, keepdim=True)

    def field(self, H_fn, z):
        with torch.enable_grad():
            point = z if z.requires_grad else z.detach().requires_grad_(True)
            return self.symplectic_gradient(scalar_gradient(H_fn(point), point))

    def pullback_defect(self, jacobian):
        if jacobian.shape[-2:] != self.J.shape:
            raise ValueError("a square canonical-to-canonical Jacobian is required")
        return jacobian.transpose(-1, -2) @ self.J @ jacobian - self.J

class SymplecticAutoencoder(nn.Module):
    """Differential autoencoder; latent Hamiltonian dynamics, not an identifiable canonical encoder.

    `variational` refers to the dynamical objective, not a probabilistic ELBO.
    A single position image cannot determine an unobserved velocity; supply history features.
    """

    def __init__(
        self,
        obs_dim,
        spatial_dim,
        hidden_dim=64,
        tangent_weight=0.01,
        prediction_weight=1.0,
        observation_noise_variance=0.0,
        solver=None,
    ):
        super().__init__()
        if min(obs_dim, spatial_dim, hidden_dim) < 1 or min(tangent_weight, prediction_weight) < 0:
            raise ValueError("invalid autoencoder configuration")
        if not math.isfinite(observation_noise_variance) or observation_noise_variance < 0:
            raise ValueError("observation noise variance must be finite and nonnegative")
        self.observation_noise_variance = observation_noise_variance
        self.solver = solver or ImplicitMidpointSolver()
        self.obs_dim, self.spatial_dim = obs_dim, spatial_dim
        self.tangent_weight, self.prediction_weight = tangent_weight, prediction_weight
        self.encoder = nn.Sequential(
            nn.Linear(obs_dim, hidden_dim), SmoothSoftplus(), nn.Linear(hidden_dim, 2 * spatial_dim)
        )
        self.decoder = nn.Sequential(
            nn.Linear(2 * spatial_dim, hidden_dim), SmoothSoftplus(), nn.Linear(hidden_dim, obs_dim)
        )
        self.structure = SymplecticStructure(spatial_dim)

    def forward(self, x):
        if x.shape[-1] != self.obs_dim:
            raise ValueError("wrong observation dimension")
        z = self.encoder(x)
        return z, self.decoder(z)

    def compute_loss(self, x_seq, dt, H_fn):
        if (
            x_seq.ndim != 3
            or x_seq.shape[1:] != (2, self.obs_dim)
            or not torch.isfinite(x_seq).all()
            or not math.isfinite(dt)
            or dt <= 0
        ):
            raise ValueError("expected finite [B,2,obs_dim] and positive dt")
        with torch.enable_grad():
            z0, r0 = self(x_seq[:, 0])
            _z1, r1 = self(x_seq[:, 1])
            if not z0.requires_grad:
                z0 = z0.requires_grad_(True)
            field = self.structure.field(H_fn, z0)
            _, tangent = torch.autograd.functional.jvp(self.decoder, z0, field, create_graph=True)
            rec = (r0 - x_seq[:, 0]).square().mean() + (r1 - x_seq[:, 1]).square().mean()
            tangent_loss = ((x_seq[:, 1] - x_seq[:, 0]) / dt - tangent).square().mean()
            # Integrated observation residual avoids the dt^-2 amplification of sensor noise.
            # The actual temporal prediction always uses implicit midpoint, never an Euler fallback.
            predicted = self.solver.integrate_step(z0, lambda z: self.structure.field(H_fn, z), dt)
            prediction = (self.decoder(predicted) - x_seq[:, 1]).square().mean()
            noise_scale = 1 + 2 * self.observation_noise_variance / (dt * dt)
            total = (
                rec
                + self.tangent_weight * tangent_loss / noise_scale
                + self.prediction_weight * prediction
            )
        return {
            "total_loss": total,
            "rec_loss": rec,
            "tangent_loss": tangent_loss,
            "prediction_loss": prediction,
        }

import torch

class SymplecticEKF:
    """Euclidean EKF in canonical latent coordinates; measurement updates are not symplectic maps."""

    def __init__(self, spatial_dim, Q_cov=1e-5, R_cov=1e-2, *, solver=None):
        if spatial_dim < 1 or not all(math.isfinite(v) and v > 0 for v in (Q_cov, R_cov)):
            raise ValueError("invalid EKF configuration")
        self.n = 2 * spatial_dim
        self.Q_cov, self.R_cov = Q_cov, R_cov
        self.solver = solver or ImplicitMidpointSolver()

    def _validate(self, z, covariance):
        if z.ndim != 2 or z.shape[-1] != self.n or covariance.shape != (len(z), self.n, self.n):
            raise ValueError("expected z[B,2d] and P[B,2d,2d]")
        if not torch.isfinite(z).all() or not torch.isfinite(covariance).all():
            raise ValueError("nonfinite EKF input")
        if not torch.allclose(covariance, covariance.transpose(-1, -2), rtol=1e-5, atol=1e-7):
            raise ValueError("covariance must be symmetric")
        if torch.linalg.eigvalsh(covariance).min() < -1e-7:
            raise ValueError("covariance must be positive semidefinite")

    def predict(self, z_post, P_post, vector_field_fn, dt):
        self._validate(z_post, P_post)
        states, covariances = [], []
        for z, P in zip(z_post, P_post):

            def flow(point):
                return self.solver.integrate_step(point[None], vector_field_fn, dt)[0]

            with torch.enable_grad():
                point = z.detach().requires_grad_(True)
                prior = flow(point)
                M = torch.autograd.functional.jacobian(flow, point)
            covariance = M @ P @ M.T + self.Q_cov * torch.eye(
                self.n, device=P.device, dtype=P.dtype
            )
            states.append(prior.detach())
            covariances.append(((covariance + covariance.T) / 2).detach())
        return torch.stack(states), torch.stack(covariances)

    def update(self, z_prior, P_prior, x_observed, decoder_fn):
        self._validate(z_prior, P_prior)
        if (
            x_observed.ndim != 2
            or len(x_observed) != len(z_prior)
            or not torch.isfinite(x_observed).all()
        ):
            raise ValueError("invalid observations")
        states, covariances = [], []
        for z, P, x in zip(z_prior, P_prior, x_observed):
            with torch.enable_grad():
                point = z.detach().requires_grad_(True)
                predicted = decoder_fn(point[None])[0]
                C = torch.autograd.functional.jacobian(lambda p: decoder_fn(p[None])[0], point)
            if predicted.shape != x.shape:
                raise ValueError("decoder and observation dimensions differ")
            R = self.R_cov * torch.eye(len(x), device=P.device, dtype=P.dtype)
            S = C @ P @ C.T + R
            # SPD solve, not an explicitly formed inverse.
            chol = torch.linalg.cholesky((S + S.T) / 2)
            K = torch.cholesky_solve(C @ P, chol).T
            state = z + K @ (x - predicted.detach())
            residual = torch.eye(self.n, device=P.device, dtype=P.dtype) - K @ C
            covariance = residual @ P @ residual.T + K @ R @ K.T  # Joseph form
            states.append(state.detach())
            covariances.append(((covariance + covariance.T) / 2).detach())
        return torch.stack(states), torch.stack(covariances)

import math

import numpy as np


class ConstrainedSTLSQ:
    """Monotone-support STLSQ; polynomial for a fixed explicit library, no L0 optimality claim."""

    def __init__(self, threshold=0.05, alpha=1e-4, max_iter=20):
        if not all(math.isfinite(v) and v >= 0 for v in (threshold, alpha)) or max_iter < 1:
            raise ValueError("invalid STLSQ controls")
        self.threshold, self.alpha, self.max_iter = threshold, alpha, max_iter
        self.n_iter_ = 0
        self.coefficients_ = None

    def _solve(self, X, y, C, alpha):
        if X.shape[1] == 0:
            return np.empty(0)
        basis = np.eye(X.shape[1])
        if C is not None and C.size:
            _, singular, vh = np.linalg.svd(C, full_matrices=C.shape[0] < C.shape[1])
            tol = max(C.shape) * np.finfo(float).eps * (singular[0] if len(singular) else 1)
            rank = int(np.sum(singular > tol))
            basis = vh[rank:].T
            if basis.shape[1] == 0:
                return np.zeros(X.shape[1])
        design = X @ basis
        if alpha:
            design = np.concatenate((design, np.sqrt(alpha) * np.eye(basis.shape[1])))
            y = np.concatenate((y, np.zeros(basis.shape[1])))
        return basis @ np.linalg.lstsq(design, y, rcond=None)[0]

    def fit(self, Theta, Target, feature_names, *, constraints=None):
        X = np.asarray(Theta, dtype=float)
        y = np.asarray(Target, dtype=float)
        if y.ndim == 2 and y.shape[1] == 1:
            y = y[:, 0]
        if (
            X.ndim != 2
            or y.shape != (len(X),)
            or min(X.shape) < 1
            or len(feature_names) != X.shape[1]
            or not np.isfinite(X).all()
            or not np.isfinite(y).all()
        ):
            raise ValueError("expected finite Theta[N,M], Target[N,1], and M feature names")
        C = None if constraints is None else np.asarray(constraints, dtype=float)
        if C is not None and (C.ndim != 2 or C.shape[1] != X.shape[1] or not np.isfinite(C).all()):
            raise ValueError("constraints must be a finite matrix C[:,M], enforcing C @ xi=0")
        scales = np.sqrt(np.mean(X * X, axis=0))
        nonzero = scales > np.finfo(float).eps
        scales = np.where(nonzero, scales, 1.0)
        normalized = X / scales
        normalized_C = None if C is None else C / scales
        active = nonzero.copy()
        coefficients = np.zeros(X.shape[1])
        coefficients[active] = self._solve(
            normalized[:, active], y, None if C is None else normalized_C[:, active], self.alpha
        )
        for iteration in range(self.max_iter):
            support = active & (np.abs(coefficients) >= self.threshold)
            self.n_iter_ = iteration + 1
            stable = np.array_equal(active, support)
            active = support
            coefficients[:] = 0
            coefficients[active] = self._solve(
                normalized[:, active],
                y,
                None if C is None else normalized_C[:, active],
                0.0 if stable else self.alpha,
            )
            if stable:
                break
        # Final debiasing refit on the selected support, still respecting homogeneous constraints.
        coefficients[:] = 0
        coefficients[active] = self._solve(
            normalized[:, active], y, None if C is None else normalized_C[:, active], 0.0
        )
        coefficients /= scales
        predictions = X @ coefficients
        variance = np.sum((y - y.mean()) ** 2)
        error = np.sum((y - predictions) ** 2)
        r2 = float(1 - error / variance) if variance > 1e-24 else float(error <= 1e-24)
        terms = [
            f"{coefficient:.10g}\\,({name})"
            for coefficient, name in zip(coefficients, feature_names)
            if coefficient != 0
        ]
        formula = " + ".join(terms).replace("+ -", "- ") or "0"
        self.coefficients_ = coefficients.copy()
        return formula, coefficients.copy(), r2

    def fit_gradient(self, dictionary, z, target_gradients, *, constraints=None):
        gradients, names = dictionary.gradient_library(z)
        target = target_gradients.detach().cpu().numpy()
        if target.shape != tuple(z.shape):
            raise ValueError("target gradients must have shape [N,2d]")
        design = gradients.permute(0, 2, 1).detach().cpu().numpy().reshape(-1, len(names))
        return self.fit(design, target.reshape(-1), names, constraints=constraints)

from itertools import combinations_with_replacement
from math import comb

import torch


class FunctionalDictionary:
    """Fixed-degree explicit dictionary with a hard feature budget, units and scaling filters."""

    def __init__(
        self,
        variable_names,
        max_poly_order=3,
        include_trig=True,
        *,
        include_kepler=False,
        max_features=2048,
        scaling_weights=None,
        target_scaling=None,
        variable_units=None,
        target_units=None,
    ):
        n = len(variable_names)
        if n < 1 or len(set(variable_names)) != n or max_poly_order < 1:
            raise ValueError("invalid dictionary variables or degree")
        count = (
            comb(n + max_poly_order, max_poly_order)
            + (2 * n if include_trig else 0)
            + (n // 2 if include_kepler else 0)
        )
        if count > max_features:
            raise ValueError(f"dictionary would contain {count} features, budget is {max_features}")
        if include_kepler and n % 2:
            raise ValueError("Kepler terms require canonical q,p coordinates")
        if scaling_weights is not None and len(scaling_weights) != n:
            raise ValueError("one scaling weight per variable is required")
        if variable_units is not None and (
            len(variable_units) != n or len({len(u) for u in variable_units}) != 1
        ):
            raise ValueError("invalid variable units")
        if include_kepler and (scaling_weights is not None or variable_units is not None):
            raise ValueError(
                "supply radial units/scaling explicitly in a custom library; automatic Kepler filtering is unsupported"
            )
        if (
            variable_units is not None
            and target_units is not None
            and len(variable_units[0]) != len(target_units)
        ):
            raise ValueError("target and variable unit dimensions differ")
        self.variable_names = list(variable_names)
        self.features = []
        for degree in range(max_poly_order + 1):
            for indices in combinations_with_replacement(range(n), degree):
                if scaling_weights is not None and target_scaling is not None:
                    weight = sum(scaling_weights[i] for i in indices)
                    if abs(weight - target_scaling) > 1e-12:
                        continue
                if variable_units is not None and target_units is not None:
                    units = tuple(
                        sum(variable_units[i][k] for i in indices) for k in range(len(target_units))
                    )
                    if units != tuple(target_units):
                        continue
                name = " ".join(variable_names[i] for i in indices) or "1"
                self.features.append(("poly", indices, name))
        if include_trig:
            for i, name in enumerate(variable_names):
                dimensionless = variable_units is None or not any(variable_units[i])
                target_dimensionless = target_units is None or not any(target_units)
                scale_ok = scaling_weights is None or (
                    scaling_weights[i] == 0 and target_scaling in (None, 0)
                )
                if dimensionless and target_dimensionless and scale_ok:
                    for op in ("sin", "cos"):
                        self.features.append((op, (i,), f"\\{op}({name})"))
        if include_kepler:
            for i in range(n // 2):
                self.features.append(("radial", (i,), f"{variable_names[i]}/r"))
        if not self.features:
            raise ValueError("dimensional/scaling filters eliminated all features")

    def build_library(self, z):
        if z.ndim != 2 or z.shape[1] != len(self.variable_names) or not torch.isfinite(z).all():
            raise ValueError("expected finite [B,variable_count]")
        values = []
        for op, indices, _ in self.features:
            if op == "poly":
                value = z[:, list(indices)].prod(-1) if indices else torch.ones_like(z[:, 0])
            elif op == "sin":
                value = z[:, indices[0]].sin()
            elif op == "cos":
                value = z[:, indices[0]].cos()
            else:
                radius = torch.linalg.vector_norm(z[:, : z.shape[1] // 2], dim=-1)
                if (radius <= torch.finfo(z.dtype).eps).any():
                    raise ValueError("Kepler dictionary undefined at collision r=0")
                value = z[:, indices[0]] / radius
            values.append(value)
        return torch.stack(values, -1), [f[2] for f in self.features]

    def gradient_library(self, z):
        point = z.detach().requires_grad_(True)
        values, names = self.build_library(point)
        gradients = []
        for column in values.unbind(-1):
            gradient = (
                torch.autograd.grad(column.sum(), point, retain_graph=True)[0]
                if column.requires_grad
                else torch.zeros_like(point)
            )
            gradients.append(gradient)
        return torch.stack(gradients, 1), names

    def conservation_constraints(self, z, vector_field_fn):
        gradients, _ = self.gradient_library(z)
        field = vector_field_fn(z).detach()
        return torch.einsum("bmn,bn->bm", gradients, field)

class DegenerateGaugeError(RuntimeError):
    """No normalized independent scalar generator exists for this candidate/reference set."""


class GaugeFixedNoetherMiner(nn.Module):
    """Sobolev Gram-Schmidt of scalar functions; never divides by u^T J u.

    Gauge coefficients are constant with respect to query z, preserving integrability.
    Guarantees concern the fixed reference set, not every point of phase space.
    """

    def __init__(self, spatial_dim, hidden_dim=64, orth_weight=5.0, norm_weight=10.0):
        super().__init__()
        self.structure = SymplecticStructure(spatial_dim)
        self.network = smooth_mlp(2 * spatial_dim, (hidden_dim, hidden_dim))
        # The gauge removes additive constants exactly; do not optimize an unidentifiable bias.
        self.network[-1].register_parameter("bias", None)
        self.orth_weight, self.norm_weight = orth_weight, norm_weight
        self.register_buffer("reference", torch.empty(0, 2 * spatial_dim))
        self._hamiltonian = None

    def set_reference(self, points, H_model):
        if (
            points.ndim != 2
            or len(points) < 4
            or points.shape[-1] != self.structure.J.shape[0]
            or not torch.isfinite(points).all()
        ):
            raise ValueError("need at least four finite phase-space reference points")
        self.reference = points.detach().clone()
        self._hamiltonian = weakref.ref(H_model)

    def _gauge(self):
        H_model = self._hamiltonian() if self._hamiltonian else None
        if H_model is None or not len(self.reference):
            raise RuntimeError("call set_reference(points, H_model) before evaluating the miner")
        with torch.enable_grad():
            reference = self.reference.detach().requires_grad_(True)
            f, h = self.network(reference), H_model(reference)
            df, dh = scalar_gradient(f, reference), scalar_gradient(h, reference)
            h_norm = dh.square().sum(-1).mean()
            eps = 100 * torch.finfo(reference.dtype).eps
            if not torch.isfinite(h_norm) or float(h_norm.detach()) <= eps:
                raise DegenerateGaugeError("Hamiltonian is locally constant on reference set")
            coefficient = (df * dh).sum(-1).mean() / h_norm
            residual_gradient = df - coefficient * dh
            squared_norm = residual_gradient.square().sum(-1).mean()
            perpendicular = (
                residual_gradient
                - (
                    (residual_gradient * dh).sum(-1, keepdim=True)
                    / dh.square().sum(-1, keepdim=True).clamp_min(eps)
                )
                * dh
            )
            independent = perpendicular.square().sum(-1).mean()
            if not torch.isfinite(squared_norm) or float(squared_norm.detach()) <= eps:
                raise DegenerateGaugeError("constant or energy-alias candidate rejected")
            if float(independent.detach() / squared_norm.detach()) <= eps:
                raise DegenerateGaugeError("candidate is functionally dependent on energy")
            scale = squared_norm.sqrt()
        return H_model, coefficient, f.mean(), h.mean(), scale

    def forward(self, z):
        H, a, f_mean, h_mean, scale = self._gauge()
        return (self.network(z) - f_mean - a * (H(z) - h_mean)) / scale

    def compute_orthogonalized_loss(self, z, H_model):
        if not len(self.reference):
            self.set_reference(z, H_model)
        elif self._hamiltonian() is not H_model:
            self.set_reference(self.reference, H_model)
        with torch.enable_grad():
            point = z.detach().requires_grad_(True)
            Q, H = self(point), H_model(point)
            dq, dh = scalar_gradient(Q, point), scalar_gradient(H, point)
            bracket = self.structure.pairing(dq, dh)
            comm = bracket.square().mean()
            orth = (dq * dh).sum(-1).mean().square() / (
                dq.square().sum(-1).mean() * dh.square().sum(-1).mean()
            ).clamp_min(torch.finfo(point.dtype).eps)
            norm = (dq.square().sum(-1).mean() - 1).square()
            total = comm + self.orth_weight * orth + self.norm_weight * norm
            metrics = {
                "commutator": float(comm.detach()),
                "orthogonality": float(orth.detach()),
                "unit_norm_loss": float(norm.detach()),
            }
            del Q, H, dq, dh, bracket
        return total, metrics

import pytest

class Oscillator(torch.nn.Module):
    def forward(self, z):
        return z.square().sum(-1, keepdim=True) / 2


@pytest.mark.parametrize("alias", ["constant", "energy", "energy_squared"])
def test_degenerate_generators_are_rejected(alias):
    class Candidate(torch.nn.Module):
        def forward(self, z):
            energy = Oscillator()(z)
            return (
                torch.ones_like(energy)
                if alias == "constant"
                else energy
                if alias == "energy"
                else energy.square()
            )

    H = Oscillator()
    miner = GaugeFixedNoetherMiner(2).double()
    miner.network = Candidate()
    miner.set_reference(torch.randn(48, 4, dtype=torch.float64), H)
    with pytest.raises(DegenerateGaugeError):
        miner(torch.randn(8, 4, dtype=torch.float64))


def test_normalized_scalar_gauge_exact_reference_conditions_and_backward():
    H = Oscillator()
    miner = GaugeFixedNoetherMiner(2, hidden_dim=16).double()
    reference = torch.randn(64, 4, dtype=torch.float64)
    miner.set_reference(reference, H)
    z = reference.detach().requires_grad_(True)
    Q = miner(z)
    gradient = scalar_gradient(Q, z)
    assert abs(float(gradient.square().sum(-1).mean().detach()) - 1) < 1e-10
    assert abs(float((gradient * z).sum(-1).mean().detach())) < 1e-10
    loss, metrics = miner.compute_orthogonalized_loss(z, H)
    loss.backward()
    assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in miner.parameters())
    assert metrics["unit_norm_loss"] < 1e-20
    # A Hessian of the actual scalar remains symmetric; no non-integrable pointwise projection.
    hessian = torch.autograd.functional.hessian(
        lambda point: miner(point[None]).sum(), reference[0]
    )
    torch.testing.assert_close(hessian, hessian.T, atol=1e-10, rtol=1e-10)


def calibration_pairs():
    angles = torch.linspace(0, 6, 40, dtype=torch.float64)
    q0 = torch.stack((angles.cos(), angles.sin()), -1)
    q1 = torch.stack((torch.cos(angles + 0.01), torch.sin(angles + 0.01)), -1)
    return torch.stack((q0, q1), 1)


async def test_pipeline_calibration_ingestion_checkpoint_and_real_learning(tmp_path):
    config = V2EngineConfig(
        obs_dim=2, latent_spatial_dim=1, hidden_dim=8, dtype=torch.float64, protection_mode="task"
    )
    pipeline = StreamingEpistemicPipeline(config)
    with pytest.raises(RuntimeError, match="calibrate"):
        await pipeline.ingest_sensor_tick([1.0, 0.0])
    history = pipeline.calibrate(calibration_pairs(), steps=5)
    assert len(history) == 5
    before = [p.detach().clone() for p in pipeline.adapters.active_parameters()]
    for i in range(5):
        telemetry = await pipeline.ingest_sensor_tick(calibration_pairs()[i, 0])
    assert telemetry["covariance_trace"] > 0
    assert any(not torch.equal(a, b) for a, b in zip(before, pipeline.adapters.active_parameters()))
    assert (
        pipeline.trigger_symbolic_distillation() is None
    )  # d=1 has no independent generic Noether generator.
    pipeline.consolidate_task("first")
    path = tmp_path / "model.pt"
    pipeline.save_checkpoint(path)
    restored = StreamingEpistemicPipeline.load_checkpoint(path)
    assert restored.adapters.task_ids == ["first"]
    samples = pipeline.reference
    with pipeline.adapters.task("first"), restored.adapters.task("first"):
        torch.testing.assert_close(pipeline.hamiltonian(samples), restored.hamiltonian(samples))
    assert all(not p.requires_grad for p in restored.autoencoder.parameters())
    with pytest.raises(RuntimeError, match="chart"):
        restored.calibrate(calibration_pairs(), steps=1)
    messages = []

    async def source():
        for pair in calibration_pairs()[:3]:
            yield pair[0]

    orchestrator = LiveOrchestrator(restored, capacity=2, callback=messages.append)
    await orchestrator.run(source())
    assert len(messages) == 3
    assert not orchestrator._running

def test_distillation_consolidates_only_validated_scalar():
    from cnge_v2.core_dynamics.hamiltonian_surrogate import HamiltonianSurrogate
    from cnge_v2.core_dynamics.symplectic_lora import SymplecticLoRAEngine
    from cnge_v2.manifold.canonical_symplectic import SymplecticStructure

    class Squared(torch.nn.Module):
        def forward(self, z):
            return z.square()

    class ExactEnergy(HamiltonianSurrogate):
        def __init__(self):
            torch.nn.Module.__init__(self)
            self.structure = SymplecticStructure(2, dtype=torch.float64)
            self.network = torch.nn.Sequential(
                Squared(), torch.nn.Linear(4, 1, bias=False, dtype=torch.float64)
            )
            with torch.no_grad():
                self.network[-1].weight.fill_(0.5)

    class Angular(torch.nn.Module):
        def forward(self, z):
            return z[:, :1] * z[:, 3:4] - z[:, 1:2] * z[:, 2:3]

    config = V2EngineConfig(
        4, 2, hidden_dim=8, dtype=torch.float64, stlsq_threshold=0.001, protection_mode="task"
    )
    pipeline = StreamingEpistemicPipeline(config)
    samples = torch.randn(128, 4, dtype=torch.float64)
    pipeline.calibrate(torch.stack((samples, samples), 1), steps=1)
    pipeline.reference = samples
    pipeline.hamiltonian = ExactEnergy()
    pipeline.adapters = SymplecticLoRAEngine(pipeline.hamiltonian, rank=1, protection_mode="task")
    pipeline.miner.network = Angular()
    pipeline.miner.set_reference(samples, pipeline.hamiltonian)
    result = pipeline.trigger_symbolic_distillation()
    assert result is not None
    assert result["r2"] > 0.999999
    assert pipeline.adapters.task_ids == ["discovery_1"]
    assert len(pipeline.discoveries) == 1
    # No consolidation if the variance gate fails; adapter state remains unchanged.
    pipeline.config = V2EngineConfig(
        4, 2, hidden_dim=8, dtype=torch.float64, min_discovery_variance=1e9, protection_mode="task"
    )
    assert pipeline.trigger_symbolic_distillation() is None
    assert pipeline.adapters.task_ids == ["discovery_1"]

        model.compute_loss(observations, 0, energy)


def test_noisy_128d_full_state_observation_denoising(record_property):
    # Identifiable full-state telemetry, explicitly NOT a single position-only pendulum image.
    model = SymplecticAutoencoder(
        128, 1, hidden_dim=32, tangent_weight=0, prediction_weight=0
    ).double()
    projection, _ = torch.linalg.qr(torch.randn(128, 2, dtype=torch.float64))
    state = torch.randn(256, 2, dtype=torch.float64) * 0.5
    clean = state @ projection.T
    noise_scale = 0.15 * clean.std()
    noisy = clean + noise_scale * torch.randn_like(clean)
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
    initial = float((model(noisy)[1] - clean).square().mean().detach())
    # Independent noisy reconstructions require no privileged physical-state targets in training.
    for _ in range(350):
        optimizer.zero_grad()
        _, reconstructed = model(noisy)
        loss = (reconstructed - noisy).square().mean()
        loss.backward()
        optimizer.step()
    test_state = torch.randn(256, 2, dtype=torch.float64) * 0.5
    test_clean = test_state @ projection.T
    test_noisy = test_clean + noise_scale * torch.randn_like(test_clean)
    with torch.no_grad():
        latent, reconstructed = model(test_noisy)
        r2 = 1 - (reconstructed - test_clean).square().sum() / test_clean.square().sum()
        training_latent = model.encoder(noisy)
        alignment = torch.linalg.lstsq(
            torch.cat((training_latent, torch.ones(256, 1, dtype=latent.dtype)), 1), state
        ).solution
        aligned = torch.cat((latent, torch.ones(256, 1, dtype=latent.dtype)), 1) @ alignment
        aligned_r2 = 1 - (aligned - test_state).square().sum() / test_state.square().sum()
    assert initial > float((reconstructed - test_clean).square().mean()) * 10
    record_property("observation_r2", float(r2))
    record_property("affine_aligned_latent_r2", float(aligned_r2))
    assert r2 > 0.98
    assert aligned_r2 > 0.98  # Diagnostic affine alignment, not canonical-identifiability proof.

def test_latent_flow_is_symplectic_but_rectangular_encoder_has_no_canonical_defect():
    structure = SymplecticStructure(2, dtype=torch.float64)
    z = torch.randn(4, dtype=torch.float64, requires_grad=True)
    solver = ImplicitMidpointSolver(tol=1e-14, max_iter=30)

    def flow(point):
        return solver.integrate_step(point[None], lambda x: structure.symplectic_gradient(x), 0.03)[
            0
        ]

    jacobian = torch.autograd.functional.jacobian(flow, z)
    assert structure.pullback_defect(jacobian).norm() < 1e-10
    with pytest.raises(ValueError, match="square"):
        structure.pullback_defect(torch.randn(4, 128, dtype=z.dtype))
    u = torch.randn(16, 4, dtype=z.dtype)
    assert structure.pairing(u, u).abs().max() < 1e-14


def test_ekf_reduces_noise_and_joseph_covariance_is_psd():
    dtype = torch.float64
    structure = SymplecticStructure(1, dtype=dtype)
    ekf = SymplecticEKF(1, Q_cov=1e-6, R_cov=0.15**2)
    solver = ImplicitMidpointSolver()
    true = torch.tensor([[1.0, 0.2]], dtype=dtype)
    state = true.clone()
    P = torch.eye(2, dtype=dtype)[None] * 0.01
    raw_errors, filtered_errors = [], []
    for _ in range(100):
        true = solver.integrate_step(true, lambda z: structure.symplectic_gradient(z), 0.03)
        observed = true + 0.15 * torch.randn_like(true)
        prior, covariance = ekf.predict(state, P, lambda z: structure.symplectic_gradient(z), 0.03)
        state, P = ekf.update(prior, covariance, observed, lambda z: z)
        raw_errors.append((observed - true).square().mean())
        filtered_errors.append((state - true).square().mean())
        assert torch.linalg.eigvalsh(P).min() >= -1e-12
        torch.testing.assert_close(P, P.transpose(-1, -2), atol=1e-12, rtol=1e-12)
    assert torch.stack(filtered_errors).mean() < 0.2 * torch.stack(raw_errors).mean()

import time

import numpy as np
import pytest
import torch

from cnge_v2.symbolic_distiller.constrained_stlsq import ConstrainedSTLSQ
from cnge_v2.symbolic_distiller.functional_dictionary import FunctionalDictionary


def kepler_data(seed, count=512):
    rng = np.random.default_rng(seed)
    z = rng.normal(size=(count, 6))
    z[:, :3] += np.array([2.0, 0, 0])
    q, p = z[:, :3], z[:, 3:]
    angular = np.cross(q, p)
    A = np.cross(p, angular) - q / np.linalg.norm(q, axis=1, keepdims=True)
    return z, A[:, 0]


def test_kepler_runge_lenz_five_term_recovery_and_timing(record_property):
    z, target = kepler_data(3)
    library = FunctionalDictionary(
        ["q_0", "q_1", "q_2", "p_0", "p_1", "p_2"], include_trig=True, include_kepler=True
    )
    X, names = library.build_library(torch.from_numpy(z))
    solver = ConstrainedSTLSQ(threshold=0.05)
    start = time.perf_counter()
    formula, coefficients, r2 = solver.fit(X.numpy(), target, names)
    elapsed = time.perf_counter() - start
    record_property("fit_seconds", elapsed)
    record_property("r2", r2)
    assert elapsed < 0.2, f"STLSQ took {elapsed:.3f}s on this CPU"
    assert r2 > 0.999
    assert np.count_nonzero(coefficients) == 5
    other, actual = kepler_data(19)
    values, _ = library.build_library(torch.from_numpy(other))
    predicted = values.numpy() @ coefficients
    assert 1 - np.mean((predicted - actual) ** 2) / np.var(actual) > 0.999
    assert "q_0/r" in formula
    assert solver.n_iter_ <= solver.max_iter

def test_homogeneous_symmetry_constraints_and_gradient_distillation():

def test_task_routed_sequential_dynamics_learning_and_lz_retention(record_property):
    class PolynomialEnergy(HamiltonianSurrogate):
        def __init__(self):
            torch.nn.Module.__init__(self)
            self.linear = torch.nn.Linear(3, 1, bias=False, dtype=torch.float64)
            with torch.no_grad():
                self.linear.weight[:] = torch.tensor([[1.0, 0.0, 0.0]], dtype=torch.float64)
            from cnge_v2.manifold.canonical_symplectic import SymplecticStructure

            self.structure = SymplecticStructure(2, dtype=torch.float64)

        def energy(self, z):
            q, p = z.chunk(2, -1)
            features = torch.stack(
                (
                    q.square().sum(-1) / 2,
                    q.pow(4).sum(-1),
                    q[:, 0] ** 2 * q[:, 1] - q[:, 1] ** 3 / 3,
                ),
                -1,
            )
            return p.square().sum(-1, keepdim=True) / 2 + self.linear(features)

    model = PolynomialEnergy()
    engine = SymplecticLoRAEngine(model, rank=1, protection_mode="task")
    z = torch.randn(128, 4, dtype=torch.float64) * 0.3
    baseline = engine(z).detach().clone()
    engine.register_frozen_invariant_adapter(
        "oscillator", engine.active_adapter_state(), engine.capture_activation_subspaces(z)
    )
    for name, coefficients in [("quartic", [0.0, 0.2, 0.0]), ("henon_heiles", [1.0, 0.0, 0.15])]:
        optimizer = torch.optim.Adam(engine.active_parameters(), lr=0.04)
        desired = torch.tensor(coefficients, dtype=z.dtype)
        q, p = z.chunk(2, -1)
        features = torch.stack(
            (q.square().sum(-1) / 2, q.pow(4).sum(-1), q[:, 0] ** 2 * q[:, 1] - q[:, 1] ** 3 / 3),
            -1,
        )
        target = p.square().sum(-1, keepdim=True) / 2 + (features @ desired)[:, None]
        initial = (engine(z) - target).square().mean().item()
        for _ in range(250):
            optimizer.zero_grad()
            loss = (engine(z) - target).square().mean()
            loss.backward()
            optimizer.step()
        assert (engine(z) - target).square().mean().item() < initial * 0.01
        with engine.task("oscillator"):
            assert torch.equal(engine(z), baseline)
        engine.register_frozen_invariant_adapter(
            name, engine.active_adapter_state(), engine.capture_activation_subspaces(z)
        )
    point = torch.tensor([[1.0, 0.0, 0.0, 1.0]], dtype=z.dtype)
    solver = ImplicitMidpointSolver(tol=1e-13, max_iter=30)
    max_drift = 0.0
    with engine.task("oscillator"):
        for _ in range(500):
            point = solver.integrate_step(point, model.vector_field, 0.01).detach()
            L = point[:, 0] * point[:, 3] - point[:, 1] * point[:, 2]
            max_drift = max(max_drift, abs(float(L) - 1))
            assert abs(float(L) - 1) < 1e-4
    # Explicitly task-conditioned retention; the active quartic/HH fields need not conserve Lz.
    record_property("routed_oscillator_max_lz_drift", max_drift)

Para outros sensores, forneça um iterador assíncrono de coordenadas `[d]` ao método `start_epistemic_runtime(source)` e aguarde a tarefa retornada. `stop()` cancela e coleta tarefas. import asyncio
from cnge_engine import EngineConfig

A busca simbólica pode bloquear brevemente o loop. Eventos externos têm fila limitada e quadros são descartados em favor do mais recente para clientes lentos.

SYSTEM ARCHITECTURE & MATHEMATICAL SPECIFICATION

Continuous Neuro-Geometric Epistemic Engine (CNGE)

A Production-Ready, Autonomous Scientific Discovery Architecture

1. MATHEMATICAL FORMALISM & SYSTEM FOUNDATIONS

The engine models physical and abstract dynamic phenomena on an unconstrained,
finite-dimensional, smooth canonical symplectic phase space manifold
\mathcal{M} = T^*Q \cong \mathbb{R}^{2d}, parametrized by generalized canonical
coordinates:
z = \begin{bmatrix} q \\ p \end{bmatrix} \in \mathbb{R}^{2d}, \quad q \in \mathbb{R}^d \text{ (configuration)}, \quad p \in \mathbb{R}^d \text{ (conjugate momentum)}

1.1. Differential Geometric Invariants

The manifold is equipped with a closed, non-degenerate, differential 2-form (the
canonical symplectic form) \omega \in \Omega^2(\mathcal{M}):
\omega = \sum_{i=1}^d dq^i \wedge dp^i \iff \omega(u, v) = u^T J v, \quad \forall u, v \in T_z\mathcal{M}
where J \in \text{Sp}(2d, \mathbb{R}) is the canonical skew-symmetric symplectic
matrix:
J = \begin{bmatrix} \mathbf{0}_d & \mathbf{I}_d \\ -\mathbf{I}_d & \mathbf{0}_d \end{bmatrix}, \quad J^T = -J = J^{-1}, \quad \det(J) = 1, \quad J^2 = -\mathbf{I}_{2d}

1.2. Hamiltonian Dynamics & Symplectomorphism Flow

Given a continuously differentiable parameterized energy functional
H_\theta: \mathcal{M} \to \mathbb{R}, the temporal evolution of any system state
obeys Hamilton's canonical vector field X_H \in \mathfrak{X}(\mathcal{M}):
\dot{z}(t) = X_H(z(t)) = J \nabla_z H_\theta(z(t)) \iff \begin{cases} \dot{q} = \nabla_p H_\theta(q, p) \\ \dot{p} = -\nabla_q H_\theta(q, p) \end{cases}
The trajectory map \Phi_t: \mathcal{M} \to \mathcal{M} induced by X_H defines an
exact 1-parameter group of symplectomorphisms satisfying:
\left( \frac{\partial \Phi_t(z)}{\partial z} \right)^T J \left( \frac{\partial \Phi_t(z)}{\partial z} \right) = J, \quad \det\left( \frac{\partial \Phi_t(z)}{\partial z} \right) = 1 \quad \forall t \in \mathbb{R}

1.3. Poisson Lie Algebra & Noether Conservation

For smooth functionals F, G \in C^\infty(\mathcal{M}), the bilinear,
antisymmetric Poisson bracket is defined by:
\{F, G\} = \omega(X_F, X_G) = (\nabla_z F)^T J (\nabla_z G) = \sum_{i=1}^d \left( \frac{\partial F}{\partial q^i} \frac{\partial G}{\partial p^i} - \frac{\partial F}{\partial p^i} \frac{\partial G}{\partial q^i} \right)
By Noether's Theorem, a functional Q_\phi \in C^\infty(\mathcal{M}) corresponds
to an invariant of motion along the system trajectory generated by H_\theta if
and only if its Lie derivative along X_H vanishes:
\mathcal{L}_{X_H} Q_\phi = \frac{d Q_\phi}{dt} = \{Q_\phi, H_\theta\} = (\nabla_z Q_\phi)^T J (\nabla_z H_\theta) \equiv 0
When multiple invariants \{Q_1, \dots, Q_k\} commute closure-wise, they define
the basis of a Lie algebra \mathfrak{g} with structure constants c_{ab}^c:
\{Q_a, Q_b\} = \sum_{c=1}^k c_{ab}^c Q_c

              - Output: X_H shape [B, 2*d].

            torch.Tensor:

# CNGE-v2: implemented contracts and mathematical boundaries

The v2 package replaces finite-difference momentum reconstruction, AST enumeration, soft degeneracy penalties and dense parameter-gradient protection in the recommended workflow. Legacy modules remain import-compatible and explicitly opt-in. V2 does not call the legacy AST compiler or parameter protector. It reuses the validated canonical autodiff primitives, smooth activations and implicit midpoint algorithm.

## 1. Differential coordinate learning and noise filtering

`SymplecticAutoencoder` learns an encoder/decoder with reconstruction, decoder-JVP tangent consistency and an integrated prediction residual. All temporal predictions use implicit midpoint. Solver convergence has a machine-precision floor (especially in float32) and fails explicitly when the requested iteration budget is insufficient; no infinite-horizon structural guarantee is inferred. The tangent term remains available as specified, but its contribution is normalized by `1 + 2 R/dt²` using the configured observation-noise variance. This prevents its expected white-noise contribution from diverging as the observation interval shrinks. The integrated observation loss avoids dividing noisy data by dt. Momentum is an encoder output, never a finite difference of a configuration component.

This is a differential autoencoder, not a probabilistic Gaussian VAE: the requested contract specifies no posterior, prior or KL/ELBO. It imposes a Hamiltonian **latent vector field**. It does not guarantee that an arbitrary observation map is canonical or that noisy observations uniquely identify physical q and p. Such identification requires observability, sufficient data, an appropriate model and calibration of gauge/scale.

A position-only image is identical for states `(q,+p)` and `(q,-p)`; a deterministic single-frame encoder cannot distinguish them. `ObservationHistory` provides bounded delay coordinates for a sensor needing temporal context. Configure `obs_dim = frame_dim × history_length` and calibrate on pairs of complete history windows. History improves observability but is not a universal proof of it.

For an encoder from 128 observation dimensions to 2d latent dimensions, its Jacobian is rectangular. `Dψᵀ J Dψ` is a 128×128 pullback, not the 2d×2d canonical form in the acceptance formula. No canonical observation two-form was supplied. The meaningful structural test implemented here checks the **square latent flow Jacobian**. It does not mislabel that test as proof of canonical encoder recovery.

The EKF propagates covariance with the actual midpoint Jacobian, solves the innovation system by Cholesky and uses Joseph-form covariance updates. Covariances are symmetrized and input PSD is checked. Measurement updates are dissipative statistical estimation, not symplectomorphisms; only the deterministic Hamiltonian prediction has the symplectic contract. Q and R are per-tick isotropic covariances and must be calibrated to the sensor and timestep.

## 2. A well-defined scalar gauge

For a real skew matrix J, `uᵀJu = 0` for every u. The proposed symplectic "norm" has a zero denominator, so it cannot define Gram–Schmidt. Also, the proposed symplectic correlation penalty is a normalized mean Poisson residual: it is zero for `Q=H` and does not exclude that candidate. A finite norm penalty leaves the constant candidate a stationary point even when its loss is nonzero.

V2 instead fixes a scalar-function gauge on a persistent reference set using the positive Sobolev pairing:

```
a = mean(∇f · ∇H) / mean(||∇H||²)
g = f − mean(f) − a (H − mean(H))
Q = g / sqrt(mean(||∇g||²))
```

The coefficients are constant with respect to the **query phase point**, so Q remains an actual scalar and its gradient is integrable. On the reference set this gives unit RMS gradient and zero mean Euclidean gradient correlation with H. Constants, energy aliases and candidates locally functionally dependent on energy are hard-rejected with `DegenerateGaugeError`. No epsilon division fabricates a generator from an exactly degenerate candidate. The additive network bias is removed because the gauge makes it unidentifiable.

These conditions are finite-reference conditions. They do not guarantee independent conserved quantities exist, optimizer convergence, or nondegeneracy everywhere. A generic one-degree-of-freedom autonomous system has no additional functionally independent commuting invariant; the runtime may correctly report no discovery. Training retains higher-order autodiff graphs only for a step; telemetry and buffers are detached, gradients are consumed, and temporary graph references are released.

## 3. Explicit functional dictionaries and constrained STLSQ

The dictionary contains degree-bounded monomials and optional trig functions, dynamic coordinate names, pre-regression scaling/units filtering and an enforced feature budget. For a fixed degree k, construction is polynomial in coordinate count. Allowing arbitrary k still gives combinatorial growth `M = binomial(n+k,k)`; the budget is checked **before** enumeration. There is no expression-tree search.

Runge–Lenz contains `q_i/r`, which is absent from a cubic/trig library. `include_kepler=True` adds those radial functions explicitly and rejects collisions at r=0. Without them, exact Kepler recovery would be an invalid claim. Units filtering assumes dimensionless coefficients; dimensional constants such as μ require explicit dimensional metadata/custom terms. Automatic radial scaling/units filtering is rejected rather than silently dropping required physical terms.

STLSQ normalizes columns, uses stable least squares (no explicitly inverted normal equations), monotonically prunes support, refits active terms and debiases the selected support. Optional homogeneous constraints `C ξ=0` are imposed through a numerical nullspace basis. `conservation_constraints` constructs C from library Lie derivatives along the current vector field, allowing terms to cancel collectively. Pruning individual terms just because they fail to commute would incorrectly eliminate combinations such as angular momentum. `fit_gradient` fits gradients of scalar library functions, retaining integrability and leaving the additive constant undetermined.

A conservative dense cost is `O(K (N M² + M³))`, plus constraint-SVD work, not O(M³) independent of sample count. STLSQ is not a global L0/Pareto optimizer and exact sparse recovery needs identifiability, suitable terms and adequate conditioning. Runtime/accuracy bounds are measured on a particular CPU and dataset, not guaranteed on every machine.

Distillation uses separate reference subsets for fit and validation, a variance gate, neural Poisson residual, held-out scalar R² and the compiled expression's own Poisson residual. Only then is an adapter consolidated. These are empirical checks on the learned latent model; they are not proofs about unknown physical laws. Calibration references should span multiple trajectories/energies; a single orbit alone is insufficient to establish independent invariants.

## 4. Low-rank adapters, exact snapshots and finite capacity

Adapters modify the scalar Hamiltonian, so its vector field remains Hamiltonian. Ordinary rectangular weight matrices are not symplectic matrices; the name does not assert otherwise. Base weights and inference statistics are frozen; active A/B factors are trainable. Each consolidated adapter stores its effective low-rank factors. Named task inference replays the frozen prefix of adapters in **every** layer.

Two explicit policies are available:

- **`activation` (default):** new adapter inputs are projected through the complement of an SVD-orthonormalized union of protected activation spans. Overlapping bases are merged; the incorrect formula `I − Σ U_k U_kᵀ` is never used for overlapping subspaces. Captured spans are finite-sample constraints. When a layer is saturated, `ActivationCapacityError` stops learning instead of silently returning a zero plastic gradient. Effects outside the sampled span and nonlinear network interactions still require task validation.
- **`task`:** new adapters have their full input capacity; named frozen task snapshots give deterministic retention when the correct task is routed. This is the policy used for sequential oscillator → quartic → Hénon–Heiles learning. It relies on an explicit task context and a fixed encoder/decoder. It is not context-free preservation by activation orthogonality.

An n-dimensional activation space cannot contain arbitrarily many independent protected directions while always retaining a nonempty complement. Distinct vector fields assigning different derivatives to the same state also cannot be represented by one unconditional autonomous Hamiltonian. Thus the requested unlimited plasticity and zero-degradation theorem does not follow from LoRA. V2 exposes the policy choice, hard capacity limits (including a 128-task snapshot budget), context and failure explicitly.

The coordinate chart is frozen after calibration; recalibration after consolidating tasks is rejected. Checkpoints save the chart, base/adapters, reference set, miner and optimizer states. On restore, transient EKF and sensor state are reset; runtime tasks/connections are not serialized. State restoration uses tensor-only safe loading (`weights_only=True`), and files are replaced atomically. Only use checkpoints from a source whose tensor sizes/resource requirements you trust.

## Correções e limites da especificação

1. Simpléticidade não significa conservação exata da energia nem estabilidade por tempo infinito. Há erro de discretização, arredondamento e convergência; o midpoint ajusta sua tolerância mínima à precisão do tensor. Os testes usam float64. Verificações em um estado inicial de baixa energia não provam todos os regimes caóticos.
2. O pêndulo duplo canônico não tem Hamiltoniano separável `T(p)+V(q)`. Ele é validado com midpoint; executar Yoshida separável nesse modelo seria matematicamente incorreto. O teste Yoshida de 50.000 passos usa Hénon–Heiles. Os testes mantêm o mapa tangente cumulativo, sem confundi-lo com Jacobianos isolados.
3. O objetivo Noether tem vários mínimos e degenerações. O teste de aprendizado exige redução mensurável, não finge que a otimização tem uma solução única Lz. O teste de cristalização recebe o Lz analítico como alvo. A descoberta neural irrestrita solicitada permanece uma meta de pesquisa não demonstrada.
4. A penalização de variância não garante não trivialidade nem independência funcional. Um invariante varia entre órbitas, mas é constante numa órbita individual. O runtime conserva um buffer de uma sequência e pode corretamente não produzir nenhuma descoberta. Pontos intercalados de uma mesma trajetória não são amostras IID nem comprovam generalização física. A saída é um candidato empírico.
5. A projeção em parâmetros é Euclidiana; não há forma simplética canônica dada sobre os pesos. Com damping positivo ela não é uma projeção ortogonal exata. Mesmo sem damping a restrição é apenas local e de primeira ordem; médias de sensibilidades podem cancelar e a base fica desatualizada. Não se comprovou retenção de Runge–Lenz após aprender um sistema quártico. Os testes não substituem esse experimento por uma alegação equivalente.
6. A busca simbólica é finita e pode não alcançar o R² solicitado; o chamador deve verificar fidelidade. A fronteira é calculada sobre candidatos visitados e usa contagem de nós como proxy de descrição, não um mínimo global de Kolmogorov. Ajustes polinomiais precisam de domínios suficientemente informativos. Operações fora do domínio real são descartadas sem mudar a fórmula.
7. Uma seção genérica de Poincaré não possui automaticamente coordenadas intrínsecas: por padrão retornam-se interseções em 2d; `chart_fn` fornece o mapa para 2d−1. A estimativa de dimensão é finita e depende das escalas e da amostragem; não demonstra existência de atratores dissipativos em sistemas Hamiltonianos.
8. Projeção contrastiva entre espaços de dimensões diferentes não é um difeomorfismo. Não se implementa um solver Gromov–Wasserstein nem recuperação automática de literatura. Embeddings sem treinamento pareado não identificam conceitos físicos por si sós.
9. Projeção para dimensão 3 é exclusivamente visual. Não existe forma simplética não degenerada em dimensão ímpar.
10. O filtro `p≈m dq/dt` pressupõe massa constante, coordenadas calibradas e intervalos uniformes. Não é um filtro canônico universal, especialmente no pêndulo duplo. A primeira amostra não entra no treinamento, pois não possui estimativa de velocidade.
11. Não há benchmark RTX, validação CUDA, captura de câmera real, modelo fundacional remoto, WebRTC, provas físicas, autenticação multiusuário ou SLA de produção nesta entrega. O canvas redesenha até a taxa do navegador e o servidor limita envio a 60 Hz; isso não comprova 60 FPS ou 120 atualizações/s. Os parâmetros e recursos dependem de dimensões/modelos escolhidos, não são tratados como orçamento garantido.
12. A configuração padrão serve a CPU. As redes especificadas somam mais parâmetros do que os números indicados no orçamento do anexo; o código prioriza as assinaturas e dimensões solicitadas, sem alegar que respeita o total estimado de 200 mil.

def test_exact_and_damped_projection_with_dependent_constraints():
    gradient = torch.randn(20, dtype=torch.float64)

def test_hamiltonian_learning_backpropagates():
    m = SymplecticManifold(1, dtype=torch.float64)
    H = HamiltonianNN(m, (16,))
    z = torch.randn(64, 2, dtype=torch.float64)
    dt = 0.01
    field = z @ m.J.T
    pairs = torch.stack((z - dt * field / 2, z + dt * field / 2), 1)
    optimizer = torch.optim.Adam(H.parameters(), lr=0.01)
    initial = float(H.trajectory_loss(pairs, dt).detach())
    for _ in range(60):
        optimizer.zero_grad()
        loss = H.trajectory_loss(pairs, dt)
        loss.backward()
        optimizer.step()
    assert float(H.trajectory_loss(pairs, dt).detach()) < initial * 0.5
    H.eval()
    with torch.no_grad():
        assert H.predict_vector_field(z).shape == z.shape

import pytest
import torch

from cnge_engine.math_core.integrators import ImplicitMidpointIntegrator, Yoshida4thIntegrator
from cnge_engine.math_core.symplectic import SymplecticManifold, scalar_gradient


def henon_heiles(z):
    q, p = z.chunk(2, -1)
    return (
        (q.square().sum(-1) + p.square().sum(-1)) / 2
        + q[..., 0] ** 2 * q[..., 1]
        - q[..., 1] ** 3 / 3
    )


def double_pendulum(z):
    # Canonical equal-mass/equal-length double pendulum; velocities are NOT momenta.
    q, p = z.chunk(2, -1)
    cosine = torch.cos(q[..., 0] - q[..., 1])
    kinetic = (p[..., 0] ** 2 + 2 * p[..., 1] ** 2 - 2 * p[..., 0] * p[..., 1] * cosine) / (
        2 * (2 - cosine**2)
    )
    return kinetic - 2 * torch.cos(q[..., 0]) - torch.cos(q[..., 1])


@pytest.mark.parametrize("H", [henon_heiles, double_pendulum])
def test_midpoint_nonlinear_symplectic_jacobian(H):
    m = SymplecticManifold(2, dtype=torch.float64)
    z = torch.tensor([[0.1, 0.2, 0.05, -0.1]], dtype=torch.float64, requires_grad=True)
    field = lambda x: m.hamiltonian_vector_field(scalar_gradient(H(x), x))
    step = lambda x: ImplicitMidpointIntegrator(max_iters=40, tol=1e-14).step(x, field, 0.01)
    jac = torch.autograd.functional.jacobian(step, z).reshape(4, 4)
    assert m.check_symplectomorphism(jac, 1e-10)[0]
    torch.testing.assert_close(
        ImplicitMidpointIntegrator(40, 1e-14).step(step(z), field, -0.01), z, atol=1e-12, rtol=1e-12
    )

@pytest.mark.parametrize("steps", [200, pytest.param(50000, marks=pytest.mark.long)])
def test_yoshida_henon_heiles_cumulative_tangent(steps):
    # Propagate the full tangent map; checking only individual step Jacobians is insufficient.
    dtype = torch.float64
    m = SymplecticManifold(2, dtype=dtype)
    q = torch.tensor([[0.1, 0.0]], dtype=dtype)
    p = torch.tensor([[0.0, 0.2]], dtype=dtype)
    tangent = torch.eye(4, dtype=dtype)
    integrator = Yoshida4thIntegrator()

    def grad_v(q):
        return torch.stack(
            (q[..., 0] + 2 * q[..., 0] * q[..., 1], q[..., 1] + q[..., 0] ** 2 - q[..., 1] ** 2), -1
        )

    def mapping(z):
        return torch.cat(integrator.step_separable(*z.chunk(2, -1), grad_v, lambda p: p, 0.01), -1)

    z = torch.cat((q, p), -1)
    maximum = 0.0
    for _ in range(steps):
        local = torch.func.jacrev(mapping)(z).reshape(4, 4)
        tangent = local @ tangent
        z = mapping(z)
        error = float(torch.linalg.matrix_norm(tangent.T @ m.J @ tangent - m.J))
        maximum = max(maximum, error)
    assert maximum < 1e-6

        assert torch.linalg.matrix_norm(tangent.T @ m.J @ tangent - m.J) < 1e-6

"""Deterministically concatenate tracked project text files, excluding the export itself."""

import argparse
import hashlib
import subprocess
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]


def export(output):
    names = subprocess.check_output(["git", "ls-files", "-z"], cwd=ROOT).decode().split("\0")
    names = sorted(n for n in names if n and n != "CNGE_SOURCE.txt" and (ROOT / n).is_file())
    chunks = [
        "CNGE — complete source archive (UTF-8)\n",
        "Each FILE section contains the original text of one tracked project file.\n",
    ]
    for name in names:
        data = (ROOT / name).read_bytes()
        text = data.decode("utf-8")
        chunks.append(
            f"\n{'=' * 80}\nFILE: {name}\nSHA256: {hashlib.sha256(data).hexdigest()}\n{'=' * 80}\n{text}"
        )
        if not text.endswith("\n"):
            chunks.append("\n")
    output.write_text("".join(chunks), encoding="utf-8")
    return len(names)


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--output", type=Path, default=ROOT / "CNGE_SOURCE.txt")
    print(f"Exported {export(parser.parse_args().output)} files")
